# MarioTrickster 设计宪法 v1.0

> 所有 AI 会话开工前**只需读这一页**。与本文冲突的旧文档一律以本文为准。
> 依据与论证：`00_好玩标准讨论稿_v0.4.md`（方向）、`v0.3`（书证与页码）。本文只写结论。
> 修改本文只能由开发者本人批准。

## 1. 游戏是什么
单人 2D 关卡游戏。**玩家 = 隐形捣蛋者**，附身、伪装在关卡道具里，布置并触发恶作剧；**AI 马里奥**按看得懂的意图闯关拿宝，会观察、起疑、学习，识破时追捕玩家。
基调：**平时是卡通闹剧，追逐时是紧张潜行。**
（1v1 本地同屏为以后的次要模式，暂不开发。）

## 2. 胜负规则
- **过关**：阻止马里奥拿宝撤离。
- **评分**：恶作剧越多、连击越多、越巧妙，分越高（类似《地狱邻居》的收视率）。
- **失败**：玩家有几条命（起始 3 条，待校准）。被识破 → 追逐；被抓住 → 扣一条命；命用完 → 本关失败。

## 3. 支柱（新想法须符合至少 2 条）
1. **预判与操纵**：读懂马里奥，诱导他读错。
2. **坑得好笑，被抓得服气**：他中招的样子好笑；你被识破时觉得"是我露馅了"。
3. **一直有事做**：观察、布局、换位、触发，没有纯等待。
4. **短关卡、爱重玩**：每关 1–3 分钟，有评分、有回放，换性格就有新体验。

**体验目标**：玩家说得出"我算准了他会走那里"和"差一点就被他发现了"。

## 4. 三层判定
**只有第 3 层能说"好玩"。AI 永远不得宣称"更好玩了/体验提升了"。**

### 第 1 层：硬规则（写成自动化测试，失败即拒绝合并）
| # | 规则 |
|---|---|
| H1 | 马里奥从任何可达状态都存在拿宝和撤离的路线；陷阱不能同时封死所有路线 |
| H2 | 马里奥起疑与识破玩家之前**必有可见预兆**（起疑值表演：问号 → 感叹号），不存在无预兆的识破 |
| H3 | 陷阱对马里奥有预警（时长按难度档位）；致命判定只在激活阶段开启，判定框不大于精灵 |
| H4 | **AI 不作弊**：马里奥只能通过规定通道感知玩家——视线（扇形 + 距离 + 遮挡）、视野内移动、延迟残留、触发暴露的**区域**、暗道声音的方向、道具异常、扫描。禁止读取附身状态或坐标 |
| H5 | 扫描结果 100% 真实；同一状态下结果相同 |
| H6 | 同一种信号外观全局只有一种含义；静音时仅凭画面也能读懂 |
| H7 | 改动马里奥的移动参数 → 自动对全部关卡重跑可达性检查 |
| H8 | 跳跃间距不落在"刚好够得着"的临界区；物理：斜向/相反键不超速、无穿透、同种子 + 同输入 ⇒ 同结果 |
| H9 | 无卡死；任何资源归零都有恢复途径 |
| H10 | 无玩家干预时，马里奥通关率 ≥95% |

### 第 2 层：结构指标（必要不充分，只能说"具备好玩的条件"）
AI 演技：
- **A1 意图可读**：暂停时开发者能预测他下一步的比例为 70–95%。
- **A2 可被操纵**：每种诱导都有效，但没有一种 100% 有效。
- **A3 起疑可见**：每关"起疑但没找到"的片段 ≥1 次。
- **A4 自然**：不抖动、不原地摇摆，反应时间呈正态分布。
- **A5 学习有度**：同一招连用第 3 次，成功率明显下降；换招后恢复；第一关不开学习。
- **A6 性格可分**：≥3 种性格，路线和扫描分布可以区分开。

关卡：
- **P1**：每关 ≥3 种坑法，没有一种占通关记录的 70% 以上。
- **P2**：每关至少 1 条可以连击 2–3 次的路线。
- **P3**：放松区、警惕区、戒备区交替出现；强度曲线非单调，高潮在收尾。
- **P4**：死区（10 秒无有效决策）占比 < 15%。
- **P5**：分段卡住率 ≥ 相邻段 2 倍时，标记并分诊。

每个系统都要过**消融测试**：关掉它，体验不变差 → 删掉。
所有数字都是起点，按试玩结果校准。

### 第 3 层：人类判定（唯一能说"好玩"的一层）
每局填写：
- "算准了"时刻有/无；
- "差点被发现"时刻有/无；
- 被抓是否服气，不服气时打原因标签：没预兆 / 看不懂他 / 手滑 / 我露馅；
- 最蠢和最聪明的动作各一个；
- 是否想再来。

每周：miniPXI 11 题（英文原题，不得改写）+ 换性格盲测。
**发布前**：3–5 名陌生人按标准脚本测试。开发者自测不能作为最终结论。

## 5. 开发顺序（不得跳步）
0. 关掉多余系统，只留跑、扫描、附身、触发；写好 H4 感知测试。
1. 一个手工房间 + 冲冲型马里奥（可读意图、起疑值、表演、追逐）。**退出条件：连玩 20 局仍想玩，且有 ≥3 种坑法**；到期做不到 → 停下重审核心动作，不加系统。
2. 做 3 个手工房间（规则生产力测试），加入谨慎型、贪财型。
3. 学习（行为解锁式）+ 评分 + 回放。
4. 逐个加回残留、热度等系统，每个都做消融测试。
5. 陌生人测试。
6. 之后才做关卡扩展、生成器、1v1 模式。

**重玩变化来自马里奥的性格、目标、入场点和学习状态，不来自地图平移。**

## 6. AI 协作规则
- 一次任务 = 一个假设 + 一个改动变量 + 事先写好的验收标准与证伪条件。
- 使用简报模板（v0.3 §3.6）。开工前先复述目标，结尾再复述一次。
- 实现功能的 AI 不能评判它好不好玩。
- 调参值放数据文件，玩法代码里不写字面常量。
- 每次会话结束时交付一个可玩构建 + 一项开发者能亲眼看到的东西；测试全绿不算完成。
- 修"不公平"时先改呈现（预兆、可见度），后改数值；发现压倒性打法时先加代价，不先禁用。
- 时间不够时砍功能，不降阈值。
- **绝不交给 AI 的事**：定义好玩、批准验收标准、跨系统取舍、声明目标通关率、最终关卡取舍。
