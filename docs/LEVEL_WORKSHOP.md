# 关卡工坊（S189）

菜单 **MarioTrickster → Level Workshop（关卡工坊）**，快捷键 **Ctrl+Shift+L**。

## 怎么搭

| 操作 | 效果 |
|---|---|
| 左边点一个元素 | 选中（黄框）。鼠标停在上面看"干什么 / 摆在哪" |
| 画布上左键点/拖 | 画 |
| 右键 / 橡皮工具 | 擦除 |
| Shift + 拖 / 矩形工具 | 一次画一块矩形（铺地面、砌墙） |
| Alt + 点 / 吸管工具 | 吸取格子里的元素 |
| Ctrl+Z | 撤销整笔 |
| 数字 1 / 2 / 3 | 随机槽位：每局随机成 箱子或草丛 / 草丛或空 / 火或空 |

M、T、G、宝物 o 只能有一个：再画一个 = 移动过去。

## 自动检查（每次改动都跑）

| 检查 | 查什么 |
|---|---|
| 摆放规则 | 脚下悬空、唯一元素重复、炮口前 3 格被挡、第 1 步不能用的元素 |
| 结构（L1） | 跳不过去的缝、太高的台阶等 |
| 死局分析 | 马里奥能拿到宝物、拿到后能回出口；**塌桥塌掉后**掉下去的人还能不能出去；封路墙升起时哪些格暂时出不去 |

问题直接画在格子上：**红框 = 必须改**，黄框 = 提示。鼠标停在格子上看原因。
打开 **最坏情况预览**：所有塌桥塌掉、封路墙升起时，红色 = 死局格，黄色 = 暂时出不去的格。

有红框时"试玩"按钮是灰的——死局在搭建时就拦住，而不是玩的时候才发现。

## 试玩

**▶ 作为第 1 步房间试玩**：保存到 `Assets/Levels/Step1CustomRoom.txt`，用恶作剧房间的全部规则开玩（马里奥心智、问卷、随机、连招、防卡死）。
之后 `▶ Play Prank Room` 也会玩这张图，直到点"恢复默认恶作剧房间"。

## 运行时防卡死

静态检查查不到物理意外（击退、几个机关同时触发）。游戏里马里奥在赶路时 6 秒几乎没动 → 自动挪到最近的"能到出口"的安全格，屏幕提示，并记进 `step1_rounds.csv` 的 `stuck_rescues` 列。出现这个提示 = 布局有问题，截图发来即可。

## 与美术的关系

画布只改 ASCII 文字；元素名称、说明、换图键都来自 `ElementCatalog`（见 `docs/ELEMENT_LEGEND.md`）。换主题 / 拖 Sprite 不需要重新搭关卡。
