# 地道战：关卡、角色AI与真实反馈共同设计方案

研究日期：2026-09-23；首次落地：S177。当前进度以 `SESSION_TRACKER.md` 为准。

## 1. 结论与范围

目标不是地下平台更多、机关更多、Bot按键更多，而是形成可理解的循环：

**发现异常 → 试探/保留扫描 → 对手选择出手或继续隐藏 → 闯关者穿越/退让/绕行 → 捣蛋者付出换位与暴露代价 → 拿宝后带着旧情报重新判断。**

每次行动至少影响一个真实取舍：时间、信息、位置或资源；同时给对方留下可执行的回应。短暂安静可以是观察/准备，不能把无事可做的等待包装成紧张。

本文是对公开开发者资料、技术讲稿和研究论文的定向研究，不是全网穷尽、游戏实机测评或模型训练。资料中的设计经验与本项目的推论分开写；没有下载商用素材、调用远程LLM或训练强化学习模型。

**S177执行范围**：冻结S176地图、实时AI、普通输入、导航、暗线、物理、伤害和冷却。将研究转成项目内只读的设计复盘卡：全批证据、优先问题、一次只改一个变量、反证条件、真人问题；自动纳入新反馈摘要。先让真实对局决定下一处设计，而非无依据地堆行为树。

## 3. 地道战的六个设计支点

1. **地形有战术含义**：地下近路有遮挡与受控出口；地表较可读但暴露/路程代价不同；不是单纯上慢下快。
2. **局部环路，而非无边迷宫**：玩家看得见目的地，至少有一个可辨认的改变接近方向的方法；绕路需要时间，不能永远免费。
3. **信息有来源**：目视预警、扫描命中、自己走过的路径是不同证据；没有看到不等于安全。未观测的对手位置保持未知。
4. **承诺有代价**：附身、等待、出手和原生暗线旅行使用现有耗时/能量/门禁；闯关者使用扫描也失去下一次立即扫描的能力。
5. **双方有回应**：伏击方可不出手、放弃已识破的位置；闯关者可观察、穿越、撤回、在真实分岔处换路。新动作要有失败可能。
6. **返程重新决策**：旧线索不是永久占位真相。拿宝后目标方向变化，双方要重估出口、冷却和曾暴露位置，不能仅原路折返或必定换层。

“地下感”还需要土顶、洞室边界、井口、明暗/材质与声音的空间一致性；美术只帮助理解，不改变碰撞，也不能代替实际地下交手。

## 4. 三个候选遭遇原型（设计草案，尚未生成）

这是未来小型白盒实验，不是承诺本轮替换S174/S176，也不是从商业游戏复制地图。

### A. 双口洞室：近路与暴露绕行

```text
             [可读地表绕行，耗时较高]
入口观察点 === 左入口 ------------ 右出口 === 拿宝端
                 \__ 遮挡洞室 __/
                    现有F伏击位
```

- 闯关者：观察出口公开线索，决定近路还是承担绕行时间；保留扫描也是选择。
- 捣蛋者：守近路或沿现有暗线提前换口；出手后位置变得可疑，换位仍需真实时间。
- 单变量实验：只调整一个入口的观察位置/可见范围，不同时改连接和Bot。
- 反证：所有画像总选同一路，或绕行只是寻路失败回退；不能用换路计数自证。

### B. 中央井：切断视线后的再接近

```text
地表观察台 ------ 井口 ------ 另一侧观察台
                      |
洞室左侧 -------- 井底 ------ 洞室右侧
```

- 中央井是双方可走的明路，不冒充捣蛋者的原生暗线。
- 对手离开视野后只能记住旧位置；重新看见才更新。没有线索时不追踪隐藏真值。
- 单变量实验：先验证中央井的真实双向普通输入路线，再只开放一个中途分岔选择；当前端点作者导航尚不能做到这点。
- 反证：所谓侧袭只是瞬移出口命中，或分岔不可走，或AI得知隐藏路径；停止扩图。

### C. 返程交叉：旧情报是否值得相信

- 沿用同一图、同一宝物和撤离目标；不靠增加钥匙、伤害或胜负模式制造复杂度。
- 比较“旧风险记忆”与“有来源/时效的记忆”；记住入口出现过预警，不等于认定敌人仍在原处。
- 单变量实验：先只补源与发生位置证据，再在同代码A/B中启用一种记忆规则。
- 反证：无风险也必换路、空中拿宝跳过作者路点、记忆过期后仍永久回避、确认局反复振荡。

三个原型必须分别回答“双方都有什么决策”“代价是什么”“对方怎么读懂并反制”。不能靠机关数或通关率排名选赢家。

## 5. 角色AI：有限信息下的有理由行动

### 5.1 观察与信念

拟议数据：`来源实例 / 观察类型 / 发生时刻 / 当时位置 / 所在区域 / 可见性依据 / 置信类别 / 失效原因`。

- 直接看到预警：只证明当时该机关预警，不证明谁附身、不证明未来何时再用。
- 扫描命中：目前接口只给bool，不能随意归因到最近的墙；需先补真实来源证据，或保留来源未知。
- 旧风险记忆：有过风险，随着时间降低决策权重；不能假装敌人不会换位。
- 对手丢失：允许有限搜索/守候，超预算放弃；绝不继续读取隐藏Transform来更新“估计”。
- 当前通用Bot/对手有已知位置启发式；S175局部墙感知不等于整个项目已消除全知。逐消费者审计，比只新建一个Belief类更重要。

### 5.2 动作先有契约，再谈规划

| 角色/动作 | 必须知道的前提 | 真实执行 | 完成与失败分开 |
|---|---|---|---|
| 闯关者：保持推进 | 作者通路和脚下支撑有效 | 普通移动/跳跃 | 实际路点与去返完成；卡住不能标成试探 |
| 闯关者：短暂观察/退让 | 附近可见预警、安全退路、原反应等待结束 | 有预算的停步/反向输入 | 公开状态变化与位置变化；没变化则放弃，不无限等 |
| 闯关者：窗口穿越 | 实际看到同源实体后重开 | 普通前进 | 实际越过；请求不是骗招或避伤证明 |
| 闯关者：换路 | 已到真实分岔、候选路线可走、已有相关证据 | 普通导航 | 实际进入/完整走通，记录机会成本与放弃路线 |
| 捣蛋者：守位/忍住 | 自己当前可用位置、能量和公开接近信息 | 不出手也是合法选择 | 玩家是否接近及是否错失窗口；不按动作数奖励 |
| 捣蛋者：预备换位 | 自身连接、旅行/融入时间、过往公开接近证据 | 原生方向输入 | 出发→到达→就绪→实际出手；迟到照实失败 |
| 捣蛋者：放弃暴露点 | 有真实被揭穿/扫描/损失线索及合法出口 | 原输入撤离/换点 | 脱离与重新准备；不减冷却补救 |

未来选择器只对合法动作比较时间、信息、位置、资源和暴露代价；保留当前决策惯性，重大新线索/计划失败才重算。动作记录候选、否决原因和预期结果，不在日志事后杜撰动机。

先验证2–3个选择，不一次引入GOAP、效用系统、行为树与LLM四套架构。拟人不是故意乱按、不稳定或加随机失误，而是可被理解、会判断错误、能被对手利用且会根据真实新信息修正。

## 6. AI与关卡共同迭代的最小循环

1. **提出一个可证伪假设**：例如“入口外能看到F预警，但旧区域记忆拒收，因此返程没有利用线索”。这是候选原因，不能从bool扫描命中直接断定同源。
2. **锁定条件**：ASCII、暗线、作者路点、源码、Unity、物理配置、双方画像、预算和操作方式。
3. **先看无干扰对照**：同图Passive若不能执行计划路线，优先导航/几何；不称为聪明伏击或高难度。
4. **再看主动对手**：死亡/损血、停滞、超时、错误路线、正常退让分别看，死亡不自动等于坏图。
5. **拆开机会链**：生成→可见机会→决定→普通输入→实际结果→对方回应→真人感受。没采到机会不证明场内没有机会。
6. **同图单变量A/B**：首轮与确认逐槽配对，旧失败保留；全部A先跑有顺序效应，单种子/一次重复只是诊断，不作统计显著性或因果认证。
7. **只在合法路径后谈战术迁移**：未来冻结一个未参与调参的种子/几何作holdout；同几何换seed不算独立泛化；策略对每种对手交叉检验，不只挑自己擅长的一组。
8. **人工做最后判断**：给用户一张原图、一个具体问题、一份ZIP；不要求读长日志或刷到全绿。失败也导出。

### 复盘卡的优先级

证据/执行完整性 → 无干扰基础路线 → 受压路线/真实交手失败 → 局部机会采样 → 有机会但没接管 → 有输入但没完成 → 返程记忆假设 → 返程机会/节奏 → 真人复盘。

这是排查优先级，不是自动通关要求或训练奖励。不看平均值掩盖单局；不把多一次操控当更好玩；人类安全绕行无需强迫战斗。卡片给出一项下一实验、冻结项、反证条件、最多4条具体记录引用。作用域明确为本批完整洞室计划，不混入旧父链/单局/不同源码的“改善”。

新候选地图将来按拓扑角色（局部环路/观察点/两侧出口/返程交叉）归档，而非仅按seed归档。目前没有实现自动质量多样性搜索、跨图迁移训练或持续自主学习；不提前加后台任务系统。

## 7. 怎样让新机制从缺口里长出来

增加机制前必须给出：真实局号与缺口、现有手段为何不足、双方新选择、公开线索、成本、对方反制、失败/滥用风险、单变量测试、移除条件。

| 观察到的缺口 | 先尝试现有设计 | 只有仍不足才考虑（未实现） |
|---|---|---|
| 捣蛋者只能守门或追不上 | 比较合法连接与准备时机；修正非全知接近判断 | 有公开声纹、有限持续时间的出口诱饵；必须可识破，不能伪造真实扫描结果 |
| 地下看不懂危险来自哪 | 先修视线/预警/来源信息与洞室构图 | 可定位但不精确泄露身份的地面振动线索；不是全图雷达 |
| 拿宝后只是原路折返 | 先使现有双路可走、检查风险来源与有效期 | 可选一次性捷径，成本与反制必须明确；不默认加新目标物或硬门禁 |
| 多机关仍只是等冷却 | 缩短无意义路程/改变合法接近角度，查看是否真有选择 | 不以再加一种伤害陷阱作为默认答案 |

## 8. 自我质疑、迭代与审计

| 被否决/修订的初稿 | 反例 | 最终约束 |
|---|---|---|
| 地下越复杂越有趣 | 迷路、不可达与读不懂不是博弈 | 先小型可读遭遇，空间复杂度由真实分岔选择支撑 |
| 持续进化让Bot赢得更多 | PAIRED说明纯对抗可造不可解环境；获胜不是乐趣 | 无干扰基线+多策略对照，不设“死亡越多越好”目标 |
| 立即全量GOAP/效用AI替换 | S176落阶尚未实测，复杂策略会掩盖执行缺口 | 本轮仅只读复盘；动作前提/普通输入执行先稳定 |
| 入口scan命中就记附近墙 | bool事件不提供源，近处可能有多个对象 | 先采真实来源，未知保持未知；不从全知gate反推 |
| 见过危险必换地表 | 必换路会变成脚本，还可能踏入不可走的地表 | 真实分岔、可用路线、有限记忆、代价比较；不跳过路点 |
| 表面上B比A多通关即胜出 | S175地表两组策略一样仍结果不同，确认也波动 | 对照同源/完整槽；保留失败和顺序/帧差异，不宣布赢家 |
| 没有墙episode就加陷阱 | 可能是视线/记录上限/安全绕行 | 先区分采样与世界，达到上限标未知，不把0当不存在 |
| 全绿就自动生成新机制 | 582回归过，但地表0/12完整；动作成立也可能很无聊 | 运行、战术时序、玩家乐趣三个独立结论 |
| 强行恢复所有停滞 | 传送、延长预算或降低判定都能制造通过 | 实际普通输入与原预算；问题不解决就保留失败 |
| 一份好评允许机制自动上线 | 个体喜好、角色不同、样本不足 | 备注只形成下一假设，绝不自动审定乐趣或发布机制 |

三次方案审查：第一稿偏“更多地形与行为”，被信息/执行缺口否决；第二稿偏“共同学习系统”，被成本、证据不足与乐趣代理风险否决；第三稿收束为本方案和只读实验卡。这里是设计审查，不是三轮Unity实战，也不是声称项目模型已深度学习。

## 9. 执行顺序与停止条件

- **现在/S177**：方案入库、全批只读复盘卡、反例测试；S176控制代码逐字保留。旧S175应被判为优先基础路线，不应被建议继续堆陷阱。
- **下一份本地ZIP**：直接运行当前版本同图对照，验证S176落阶及完整去返，不需要先跑旧版本。预计测试数以交接和Unity发现数为准。
- **路线仍失败**：只修一个执行/几何问题；停止AI战略扩展。无干扰成功但受压失败时保留对手与时序，不把死亡一概当路径bug。
- **路线可信后**：采入口风险来源，再做一个记忆策略A/B；不同时改出入口。
- **记忆选择有效但仍单调**：先一张双口洞室的单变量拓扑试验，再跨对手/保留图检查，真人回答是否有取舍。
- **现有手段已不足**：按第7节提案，经反例审查再写机制代码；不自动产生道具。

真人问题优先一句：**“这一段你是在做选择，还是只是在等它放行？如果判断错了，你知道还能怎么应对吗？”** 角色互换体验可揭示捣蛋者是否一直无事可做，但不在本轮新增胜负规则。
