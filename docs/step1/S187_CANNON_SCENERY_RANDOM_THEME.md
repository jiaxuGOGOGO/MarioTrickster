# S187：大炮 + 场景摆件 + 受控随机 + 主题底子

> 本轮按用户要求"加入能造成伤害也能逃跑的大炮、场景摆件更方便、加入随机让涌现成为可能、为游乐园/公园/山上公园打底"。
> 全部遵守：宪法 H1/H3/H4/H6/H9、零代码新增元素（不改 AsciiLevelGenerator 核心）、调参值在数据文件、换肤空插槽保留白盒。

## 1. 恶作剧大炮（ASCII `K` 朝右 / `k` 朝左）

| 用法 | 怎么触发 | 规则 |
|---|---|---|
| 开炮 | 伪装在炮旁边，按 **L** | 预警闪烁 → 朝炮口直线打一发，打中马里奥扣 1 血 + 击退（接入原有受伤流程：马里奥被坑晕、连招全部自动生效）。每回合 `cannonShotsPerRound`（默认 1）发。 |
| 人肉炮弹（逃跑/秀操作） | 炮弹打完后，**不伪装**走进炮口 | 0.35 秒装填（走出去 = 反悔）→ 朝炮口斜上方 40° 把自己打出去，约 8–9 格远。解除伪装（会被看见），冷却 2.5 秒后可再用。 |

规则参考（只借规则，不借素材/代码）：
- Donkey Kong Country 的 Barrel Cannon：钻进去，朝箭头方向发射，用于跨越与逃脱（[Super Mario Wiki](https://www.mariowiki.com/Barrel_Cannon)）。
- Super Mario 的 Bill Blaster：固定炮台朝一侧直线射击（[Super Mario Wiki](https://www.mariowiki.com/Bill_Blaster)）。

宪法约束：H3 开炮必有预警、判定只在飞行中、判定圈小于视觉；H4 大炮不给马里奥任何关于你的信息；H9 炮弹有寿命、撞墙即碎。

## 2. 场景摆件（不可操控，只负责阻挡/遮挡/装饰）

| 字符 | 名称（=主题键） | 碰撞 | 视线 |
|---|---|---|---|
| `c` | Crate 箱子 | 实心，挡路 | 挡 |
| `b` | Bush 草丛 | 可穿过 | 挡（马里奥自己走进同一丛就看得见） |
| `d` | Decor 装饰 | 无 | 不挡 |

**摆放**：ASCII 模板里直接写字符；或 Test Console → Level Builder →"Cannon & Scenery"一行，右键进笔刷在 Scene 里刷。
**换素材**：LevelThemeProfile 的 elementSprites 里给 `Crate / Bush / Decor / Cannon` 拖图，不改代码。

## 3. 受控随机（涌现的来源）

| 随机 | 范围 | 为什么不破坏公平 |
|---|---|---|
| 布局槽位 | `1` 箱子或草丛、`2` 草丛或空、`3` 火或空；每回合按种子挑 | 必要元素不动；32 种组合全部通过 L1/L2 可达性（测试逐一验证） |
| 草丛起风 | 7–16 秒随机晃一次 | 与"有人在里面"外观完全一样 → 马里奥分不出，只能起疑去看（否认空间，讨论稿 v0.3 §3.3.1 第 5 条） |
| 马里奥性格 | 赶路时偶尔回头看；每回合速度 ±8% | 种子可复现，范围有上限 |

每局种子写进 `step1_rounds.csv` 的 `layout_seed` 列，任何一局都能复现。

## 4. 主题底子

调参资产 `themePreset`：`Whitebox / AmusementPark / CityPark / MountainPark`（默认游乐园）。
目前只换白盒配色，用来一眼分出风格；美术素材到位后只需往主题资产拖图。换主题后点 ▶ Play 会自动重建场景。
