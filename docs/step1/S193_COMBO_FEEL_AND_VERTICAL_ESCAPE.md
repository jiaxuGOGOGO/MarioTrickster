# S193：连招手感 + 可破坏地形 + 纵向逃脱路线图

> 用户诉求："关卡连锁设计时不明显，没有格斗游戏连招的爽感；想加机制/陷阱/可破坏地形；未来背景可能是几层楼的房间或地下一百层的监狱。"
> 本文件只写**规则与取舍**。能不能说"更好玩"只能由第 3 层人类判定决定（宪法 §4），这里只提供"具备好玩的条件"。

## 1. 为什么现在连招不爽（诊断）

| 格斗游戏里让连招爽的东西 | 本项目 S185 时的状态 | S193 改成 |
|---|---|---|
| **顿帧 hitstop**：命中瞬间画面停几帧，"打中了"有重量 | 没有 | 每次坑到停 0.05s，每多一段 +0.03s，上限 0.16s |
| **受击硬直 hitstun**：被打的人动不了，给你接下一招的窗口 | 有（晕 1.2s） | 保留 |
| **伤害递减 damage scaling**：连招越长后面越不值钱，防无限连 | 线性叠加（x5 就晕满 3s） | 递减：+0.6 → +0.42 → +0.29 … 仍有 3s 上限（H9） |
| **浮空 launcher → 追击 juggle** | 没有"起手技" | 新机关 **弹簧板 J**：把马里奥弹上天、空中不能动，落点可预判 |
| **段位反馈**：连击数、评价字、音画随段数升级 | 只有黄色"连招 x2" | x2 连击 → x3 漂亮 → x4 疯狂 → x5 大闹剧，颜色/字号/弹出逐级放大 + 震屏 |
| **多样性 > 重复**（换招才高分） | 没有分数 | 连招分：换不同机关 +5，同一种连用只算一半（呼应宪法 P1"没有一种坑法占 70%"） |

来源：Celia Wagar《Stunning Detail: Hitstun in Depth》 https://critpoints.net/2016/08/14/stunning-detail/ （hitstop、hitstun、juggle、递减）；
bb010g《Thoughts on combos》 https://gist.github.com/bb010g/5fd8de887b9749ad35f84584af2f0c45 （length / paths / variety）。只借规则，不借素材与代码。

## 2. 新机关（本次交付 3 个，都是零代码扩展：Registry + Catalog，不改生成器核心）

| 字符 | 名字 | 平时 | 按 L 后 | 连招角色 |
|---|---|---|---|---|
| `J` | 弹簧板 | 普通实心地面，安全 | 预警 0.4s → 把站在板上的马里奥弹高 ~5 格，空中 0.6s 不能动 | **起手 launcher**：弹起 → 落点火 / 裂缝 / 封路墙 |
| `x` | 裂缝地板 | 实心地面，安全 | 预警 0.6s → 整条相连的裂缝一起碎，本回合不复原 | **可破坏地形**：把他掉进下一层；也是多层楼/监狱的"凿地板" |
| `n` | 香蕉皮 | 地上装饰，可穿过 | 预警 0.4s → 1.2s 内踩上去就朝前滑 ~3.5 格（空中/地面失控 0.5s） | **打乱落点**：把他滑进火、裂缝或封路墙前 |

规则保障：
- H3：两者都有预警（数值在 RushMarioTuning 里可调）。
- H1/H9：裂缝地板在死局分析里按"**永久打开**"处理（和塌桥同一套最坏情况）；关卡工坊画出"碎了就出不去"的地板会直接标红，提示"给下面留一条回去的路（单向台面 `-` 或弹簧）"。
- H4：两者只改马里奥速度 / 地形，不读取捣蛋者任何信息；连招事件不带捣蛋者信息。
- H10：平时都是实心可站，不干预时马里奥照常通关。

默认恶作剧房间里：弹簧板放在第一区地面（x=13），裂缝地板放在宝物前（x=39–41），下面是一格深的地下室（有单向台面能跳回来）。
示例连招路线："他走到弹簧板 → L 弹起 → 他落在火旁 → 切到火 L" / "他拿宝回头 → 裂缝 L 掉地下室 → 封路墙 L 挡出口方向"。

## 2b. 关卡工坊"连招路线"开关（设计时就能看见连锁）

工具条新增 **连招路线**：把"离得够近、能在连招窗口内依次坑到马里奥"的机关用同色弧线连起来，一种颜色 = 一套连招；
底部显示"最长一套 N 个机关、M 种不同机关"。规则：水平距离 ≤ `comboRouteCells`（默认 10 格 ≈ 4 秒窗口 × 马里奥速度，可调），
高度差 ≤ 3 格；起手招（弹簧板/香蕉皮/大炮）多算 3 格。这只是**设计提示**，真实能不能连仍以试玩为准。

## 3. 背景设定：几层楼 / 地下一百层监狱

### 3a. S195 已实现（用户要求暂时跳过"连玩 20 局"门槛）

| 功能 | 说明 |
|---|---|
| **楼层寻路** `LevelPathPlanner` | 宝物与出口不在同一层时，马里奥会先去楼梯口（按网格找路：走、跳 ≤2 格、下落、单向台面可从下穿过）。同层房间（默认恶作剧房间）自动不启用，行为不变。只看地形与自己的目标（H4）。 |
| **监狱塔生成** `FloorStacker` | 关卡工坊"监狱塔…"菜单：2–11 层，每层从手工楼层模板里选（随机的是组合，Spelunky 式），楼梯口左右交替 → 每层都要横穿、经过该层机关；宝物在最底层，出口在顶层。所有层数 × 种子都过死局检查（测试校验）。 |
| **加一层** | 工坊"监狱塔… → 在当前房间上面加一层"。 |
| **高楼镜头** | 房间高于 `maxWholeRoomHeight`（默认 16 格）时，镜头默认"框住两人"（C 键仍可切换）。 |
| **防卡死救援提速** | 高楼房间"能回出口的格"开局预算、剪枝（结果不变，11 层 0.41s → 0.25s，且不在游戏中途计算）。 |

一个画布最多 48 行 ≈ 11 层；"地下一百层" = 多个塔串联（下一步：塔与塔之间用出口→下一座塔入口衔接）。

### 3b. 仍未实现（路线图）

宪法 §5 规定："第 1 步退出条件（连玩 20 局仍想玩，且 ≥3 种坑法）达成前，不加系统"；第 6 步才做关卡扩展与生成器。
所以下面是**方向与约束**，不是这次要做的事。

| 阶段 | 做什么 | 与宪法的关系 |
|---|---|---|
| 现在（Step 1） | 单房间里验证"连招爽不爽"；新机关 J / x 已可在关卡工坊里画"两层楼"的小房间试玩 | 不跳步 |
| Step 2 | 3 个手工房间：**地面层 / 二楼 / 地下室**，每个房间一种主机关组合；加谨慎型、贪财型马里奥 | "规则生产力测试" |
| Step 3–4 | 学习、评分、回放；逐个加回残留、热度系统，做消融测试 | — |
| Step 6 | **纵向关卡**："楼层 = 房间"，房间之间用裂缝地板 / 楼梯 / 电梯连接；"地下一百层"= 房间池 + 规则化拼接（Spelunky 式：随机的是组合，每个房间都是手工的） | 宪法："重玩变化来自马里奥的性格、目标、入场点和学习状态，不来自地图平移" → 拼接只换顺序/入场点，房间本身手工保证 H1 |

题材定位建议（取舍由开发者决定）：
- **监狱逃脱反转版**：马里奥是"越狱犯"要带赃物逃上地面，你是看守监狱的隐形捣蛋鬼 → 天然"往上逃"的纵向动线，每一层是一个 1–3 分钟短关（支柱 4）。
- **几层楼的房子**：《地狱邻居》式，楼层之间的楼梯口、地板洞就是天然的"必经之路"，最适合放封路墙/裂缝地板。

参考（只借规则）：Spelunky 的可破坏地形与"随机的是组合"思路（https://www.gamedeveloper.com/design/a-spelunky-game-design-analysis-pt-2 ）；
Hitman 关卡把大地图切成风格不同但彼此连通的分区、同一地图换目标重玩（https://www.unsupervisednerds.com/reads-full/2020/8/19/level-design-in-hitman ）。

## 4. 候选机关池（未实现，按"至少满足 2 条支柱"筛过；每次只加一个 + 消融测试）

| 机关 | 连招角色 | 需要注意的规则 |
|---|---|---|
| 吊灯 / 落石 | 从上往下的"meteor"，适合楼层题材 | 判定只在下落中；落地变障碍物要留路（H1） |
| 传送门（楼层之间） | "换位追击"：他掉下去，你从传送门先到 | 不能成为玩家无限逃跑工具（加冷却/暴露） |
| 喷水 / 风扇 | 推开他（pushback），适合和封路墙配合 | 推力不能把他推进死局 |
| 监狱门 / 牢笼 | 暂时关住他（受击硬直的"抓投"） | 必须自动开启（H9），被关时起疑值上升 |

## 5. 角色能力扩展（未实现）

- 捣蛋者：**连锁触发**（伪装在两个机关中间时，一次 L 依次触发两个，第二个延迟 0.3s）→ 降低连招操作门槛；代价：暴露时间更长。
- 马里奥：**受身 tech**（被弹起后，谨慎型马里奥有概率空中调整落点）→ 让连招不是 100% 成功（宪法 A2：每种诱导都有效，但没有一种 100% 有效）。
