# S196：箱庭设计（艾尔登法环 / 黑暗之魂式）——调研结论与本次实现

> 用户诉求：监狱塔只是"无脑堆层数"，没有每层特色与层间巧思；希望体现魂系箱庭；想知道"全部展现还是转场切换"；
> 希望用心设计每一层，同时有纵览全局的视图；增加破坏墙体的技能/道具；增加随机性触发涌现。

## 1. 调研：魂系箱庭到底是什么（只借规则）

| 手法 | 出处 | 在本项目里的对应 |
|---|---|---|
| **主路 + 绕回主路的支路**（loop back），每条支路都是单向下落、最后回到熟悉的地标 | Level Design Book《Undead Burg》：各支路"一路下落、绕一圈回到起点楼梯"，下落 = 单向流动 + 地标 | 楼梯口 + 单向台面阶梯；裂缝地板 `x` = 单向下落 |
| **从另一边打开的门 / 捷径**：第一次只能看见门，绕远路后从背面打开，形成回到起点附近的捷径 | Undead Burg"绕回起点"；Stormveil 大量 one-way door（Steam/Reddit 玩家讨论） | 新元素 **捷径门 `|`**：只能从"离出生点更远的一侧"推开（构建器自动判定） |
| **可破坏物藏暗道**：木桶挡住的隐藏下落、箱子挡住的楼梯、打墙 | Undead Burg"被可破坏木桶挡住的暗道"、商人藏在箱子后 | 新元素 **裂墙 `%`** + 捣蛋者新技能 **砸墙（B）** |
| **真实空间、尽可能多的区域间连接**，让玩家能在脑中建图 | Team Cherry 谈 Hollow Knight 地图（PC Gamer）："尽可能多的区域间连接""真实空间，不做悖论房间" | 层间至少 2 条路；工坊"箱庭总览"统计每对楼层的连接数 |
| **每个区域有身份** | Hollow Knight 各区域主题；Undead Burg 每段一个"教—考—变"节拍 | 每层一个主题机关（身份），总览检查"每层主机关是否不同" |
| **随机的是组合，房间是手工的**；Team Cherry 自己试过预制房间随机拼接，结论是"不好玩也不好讲故事" | PC Gamer 采访 | 监狱塔 = 手工主题楼层 + 固定结构规则；**真正用心的关卡用手工画**（见样板） |

来源：
- Level Design Book, *Undead Burg (Dark Souls 1)* https://book.leveldesignbook.com/studies/sp/undead-burg
- PC Gamer, *How to design a great Metroidvania map*（Team Cherry 访谈） https://www.pcgamer.com/how-to-design-a-great-metroidvania-map/

## 2. 结论：全部展现 vs 转场切换

**结论：一座"楼"（一个箱庭）= 一个连续空间，全部在同一张图里、不转场；楼与楼之间（例如"地下 1–4 层"→"地下 5–8 层"）才转场。**

理由：
1. **本游戏的核心是"看"**：马里奥靠视线发现你（H4），你靠观察马里奥路线来埋伏。转场会切断视线与追逐（你在楼上、他在楼下，屏幕切了就什么都做不了），破坏捉迷藏的读招。
2. **箱庭的爽点是"原来这里通到那里"**——需要在同一空间里看见门的两侧、看见裂墙后面。Team Cherry 强调"真实空间"才能让人脑中建图。
3. **转场适合"章节"**：一座楼 4 层左右、1–3 分钟一局（宪法支柱 4：短局），大小正好是一张 48×20 的图；"一百层"= 25 座楼串联，每座楼之间转场（下一步做）。
4. **镜头**：楼高超过 16 格时镜头自动"框住两人"（S195），C 键可切换看全楼。

## 3. 本次实现（S196）

### 3a. 修复
- `MechanismExplorationPlanTests.NewRegistryEntriesAreReportedAsUnsupportedNotSilentlyCounted` 失败：S193/S194 新增的 `J x n` 没有在机制探针的"显式不探测清单"里登记 → 已登记（连同本次的 `| %`），并写明原因。

### 3b. 新元素 / 新技能
| 字符 / 按键 | 名字 | 规则 |
|---|---|---|
| `|` | 捷径门 | 平时是墙；只能从一侧贴近 0.6 秒推开，本回合保持打开。开启侧 = 离出生点更远的一侧（先绕远路才能开）。 |
| `%` | 裂墙 | 平时是墙、挡视线；可被 ①捣蛋者砸墙 ②炮弹 ③高速撞击（被弹簧/香蕉皮弹飞的人）打开，本回合不复原。 |
| **B** | 砸墙（捣蛋者） | 必须**现形**；每回合 2 次、冷却 6 秒、砸完硬直 0.5 秒；**发出响声**——14 格内马里奥隔墙也听得见（和草丛晃动同一起疑通道，只有位置，H4）。屏幕字幕"哐！"（H6）。 |
| 随机事件 | 开局塌墙 | 每回合 35% 概率，随机一面裂墙开局就已经塌了（"上一个越狱犯留下的洞"）→ 多一条秘密路线，马里奥和你都要重新判断（涌现）。种子可复现。 |

死局检查：门/裂墙/裂缝/塌桥按 **"全关"和"全开"两种最坏情况**都查（打开后如果出现回不去的单向下落，也会标红）。

### 3c. 关卡工坊
- **箱庭总览**（工具条开关）：自动缩放看整张图；画布上给每层上底色、标出每层身份；绿框 = 楼梯/台面，黄框 = 捷径门，粉框 = 裂墙/裂缝；右侧面板列出每层身份、藏身处、所有层间连接（标"要打开"），以及**通关路线步数、打通捷径后省下的步数、有没有环路**，和一份"箱庭建议"清单（每层没机关/主机关重复/没藏身处/没环路/没捷径）。
- **样板：箱庭监狱**（手工设计，四层）：
  - F1 看守所：出口、出生点；封路墙守走廊；**捷径门**在出口旁，从下面绕上来才能从背面推开。
  - F2 放风场（高 6 格）：两块弹簧板；楼板中段**裂缝地板**（把他掉进牢房区）；楼板上**裂墙竖井**直通看守所（秘密路线）。
  - F3 牢房区：塌桥横跨；右侧**牢门**（捷径门）从金库爬上来才能打开。
  - F4 金库：宝物在最右、两门大炮对射、左侧**裂墙暗室**。
- **监狱塔…**（重做）：每层不同主题（放风场·香蕉皮 / 牢房区·封路墙 / 锅炉房·火 / 看守所·大炮 / 水牢·混合 / 废墟·裂缝与香蕉），层间两条路（主楼梯口左右交替 + 另一侧的裂墙或裂缝），左侧**捷径竖井**从最底层一路通到顶层出口旁的捷径门——拿宝后绕回竖井爬上去开门 = 直通出口（4 层塔：49 步 → 打通后省 33 步）。2–11 层 × 多个种子全部通过死局检查，并且都有环路、都有真的能省路的捷径（测试校验）。

## 4. 设计建议（给做关卡的你）

1. **先画主路，再画回头路**：主路一路往下（单向下落、裂缝地板），回程靠捷径门/竖井"绕回来"。
2. **每层一个身份**：一种主机关 + 一种藏身处布局；总览里"主机关重复"会提示。
3. **门开在"远的那一侧"**：第一次路过只能看见门——这就是"以后会回来"的承诺。
4. **裂墙放在"看得见但走不到"的地方**：玩家（你）要决定"现在砸开（会被听见）还是留着"。
5. **用总览看步数**："打通捷径后省 X 步"越大，打开的爽感越强；但门关着也必须能通关。
