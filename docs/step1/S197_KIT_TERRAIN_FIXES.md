# S197：技能包（炸弹/缩小/通风管/时间静止）+ 限制地形 + 修复 + 扩展调研

## 1. 修复
| 用户反馈 | 原因 | 修法 |
|---|---|---|
| `CrackedWallAndDoorAreSafeAndSmashHasCost` 失败 | 测试把整个 MarioEyes 检查成"不能出现 TricksterController"，但 MarioEyes 本来就要持有捣蛋者（用来"看"） | 只检查"听"的入口 `NoteNoise(Vector2 where)`：只收一个位置，不碰捣蛋者（H4 的真实含义） |
| 按 B 没反应 | 项目同时开了新旧输入系统，新加的键只用旧 `Input.GetKeyDown` 读，某些机器读不到 | 新增 `Step1Keys`：新旧输入系统都读，任一按下即算；B/Z/M/Tab/↓ 全部走它 |
| 点"作为第 1 步试玩"退出后工坊全空白 | 进出 Play 模式时 Unity 只恢复了部分缓存（字符串缓存被序列化、列表缓存为空）→ 画布一画就 NullReference（截图里 `LevelWorkshopWindow.cs:337` + "layout Begin/End calls match"） | 所有缓存标 `[NonSerialized]`，画布缓存为空时自动重建 |
| 马里奥卡住 | 楼层寻路规划了"斜着跳 3–4 格上去"的路线，但 AI 只在目标水平距离 < 2.25 格时才起跳 → 走到平台正下方撞头 | 规划只用 AI 真能跳的跳法（向上跳水平 ≤ 2 格）；往上走时先把"起跳点"给他，站到起跳点才换成落点 |
| 阻挠者有些地方跳不上去 | 捣蛋者跳跃力 18 → 最高 2.0 格；关卡按 2.5 格设计 | 跳跃力改为调参 `tricksterJumpPower = 20`（≈2.5 格，与马里奥一致） |
| 想在玩的时候看清哪个是墙 | — | 新增 **M / Tab 图例**：左下角图例面板 + 场景里给可炸/可交互的东西头上标签（"可炸""从右开 →""管 1A/1B""毒""黏"） |

## 2. 新技能（全部数值在 RushMarioTuning，可配置）
| 谁 | 按键 | 技能 | 代价 / 反制 |
|---|---|---|---|
| 捣蛋者 | **B** | **炸弹 ×3**：引信 1.5 秒（闪烁 + 倒计时，H3）→ 半径 1.6 格内炸开裂墙 `%` / 裂缝地板 `x` / 箱子 `c`；马里奥在范围内晕 1 秒 + 击退（不扣命） | 必须现形；缩小时不能放；冷却 2 秒；**爆炸声 14 格内隔墙听得见**（马里奥会来查看） |
| 捣蛋者 | **Z** | **缩小 ×2**：5 秒内身体缩到一半，能钻 1 格高的缝，跑快 25%；再按 Z 提前变回 | 缩小时不能伪装、不能触发机关、不能放炸弹；头顶太低时变不回去（等能站起来才变，防卡死 H9） |
| 捣蛋者 | 站在管口按 **↓** | **通风管 `O`**：钻到配对管口（按上→下、左→右编号 1↔2、3↔4），用时 0.35 秒，冷却 3 秒 | 钻管时解除伪装；管口"咣当"一声，**近处**（听力的 1/3）马里奥听得见；马里奥自己不能用 |
| 马里奥（AI） | — | **时间静止 ×1**：他在追你、看得见你、离你 7 格内时使用（或刚被你坑过起身时）→ **预警 1 秒**（屏幕边缘蓝光 + 字幕）→ 冻结你 2 秒 | 预警期间你可以钻通风管/躲草丛（冻结时他仍要看得见你才能抓）；开局 15 秒内不用，冷却 20 秒；只冻结你，**机关照常**（你之前放的炸弹照样会炸 → 涌现） |

## 4. 调研：还可以加什么（按宪法筛选，未实现）

来源：Critical Gaming《Spelunky: A Game Design Gold Mine》——炸弹/绳索**数量有限**让每一次使用都有分量；"几乎所有东西都会被爆炸影响（玩家、敌人、地形）"；"敌人和机关会互相影响"（箭陷阱能射死敌人、火蛙爆炸像炸弹）→ 涌现来自**元素之间的互相作用**。
https://critical-gaming.com/blog/2009/2/17/spelunky-a-game-design-gold-mine.html

### 4a. 机关 / 地形候选
| 候选 | 连招角色 | 为什么适合本项目 | 必须满足的规则 |
|---|---|---|---|
| **油桶**（炸弹/火点燃 → 连锁爆炸） | 连招终结技 | 元素互相作用（Spelunky 式）：火 + 炸弹 + 油桶 = 你设计的连锁 | 爆炸前要有预警（H3）；不能炸开承重地面（H1） |
| **水坑**（火熄灭、炸弹哑火） | 反制元素 | 给马里奥"安全区"，也让你的布局有取舍 | 纯减益，不堵路 |
| **绳索 / 梯子**（只能垂直攀爬） | 移动 | Spelunky："上比下难" → 天然制造折返；楼层之间多一种连接 | AI 寻路要加"攀爬"动作（需扩展 LevelPathPlanner） |
| **铁笼 / 牢门陷阱**（关住马里奥 3 秒） | 控制技（格斗游戏的"抓投"） | 监狱题材最贴合 | 必须自动打开（H9），被关期间他起疑值上升 |
| **警报器**（踩到后马里奥全场起疑） | 反向陷阱 | 对你不利的地形：你也要避开 | 只影响起疑，不影响可达性 |
| **传送带** `>`（已有元素） | 位移 | 把他送进火/毒池 | 第 1 步已登记但未启用；需要验证 H10 |

### 4b. 技能候选
| 谁 | 候选 | 代价 |
|---|---|---|
| 捣蛋者 | **诱饵**：丢一个假的"你"（外观一样），骗马里奥追它 | 次数限制；马里奥近看会识破 |
| 捣蛋者 | **远程触发**：伪装时可以触发 2 格外的机关（而不是贴着） | 暴露时间更长 |
| 马里奥 | **手电筒 / 扫描**：照亮一片区域，伪装无效 | 已有扫描系统可复用；冷却 |
| 马里奥 | **踢门**：捷径门可以被他从错误的一侧踢开（需要时间） | 给他反制箱庭捷径的手段 |

### 4c. 优先级建议
1. **油桶**（最强的"连招/涌现"收益，复用炸弹与火）；
2. **铁笼**（最贴监狱题材，控制型连招）；
3. **诱饵**（给你一个"骗"的手段，和时间静止形成攻防）。
