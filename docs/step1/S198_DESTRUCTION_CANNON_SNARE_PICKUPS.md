# S198：可破坏地形、炸弹伤害、塌桥修复、大炮瞄准、墙上通风口、绳套、随机道具 + 涌现方向

## 1. 你报的问题 → 原因 → 修法
| 反馈 | 原因（查代码确认） | 修法 |
|---|---|---|
| 马里奥在出口下面来回跳 | ① 楼层路点在他头顶时，旧 AI 进入"头顶目标 → 左右徘徊跳"模式；② 防卡死只看"离锚点有没有动 0.6 格"，来回跳每次都动了 1–2 格 → **永远不算卡住**，救援不触发 | ① 楼层路点在上方时用"指定路线"转向（对准正下方再跳）；② 防卡死改成"**到目标的距离 6 秒内没缩短 1.5 格 = 卡住**"（来回跳、原地跳都算）→ 自动救援到最近的可回出口位置 |
| 炸弹不伤人、除机关外没有破坏效果 | 原来只炸裂墙/裂缝地板/箱子；普通地面、墙是合并的长碰撞体，炸不掉 | 新增 `Destructible`：**除机关陷阱与特殊地形外全部可炸**（地面、墙、单向台面、箱子、草丛、装饰、裂墙、裂缝地板）。长条地面被炸时**切掉被炸的格子、剩余部分重建**。**最外圈围墙与最底层地面不可炸**（否则会掉出地图，H9）。炸到马里奥扣 1 血、炸到你自己掉 1 命（都可配置 `bombDamageMario` / `bombDamageSelf`，设 0 = 只晕不伤）。回合重置时全部复原。 |
| 第二张图里的红色是什么？为什么跳起来能粘上去 | 红色竖条 = **捷径门**（从右边推开）；右边整列红色 = **外墙**（游乐园主题里墙是红色的）；右下红块 = 马里奥。"粘墙"：捣蛋者空中朝墙按方向键时，Unity 的接触求解把刚体卡在墙面上（零摩擦材质也挡不住） | 捣蛋者空中朝实心墙移动时**清掉朝墙的水平速度** → 正常滑下来 |
| 通风管只能按 ↓ | — | 通风管**贴墙时**可以朝墙按 ← / → 进（墙上的通风口）；地上的通风管按 ←→ 不会误进（旁边没墙） |
| 塌桥按 L 没反应 | 一座桥是 4 个独立格子，按 L 只塌**离你最近的那一格**，另外 3 格照样托住人 → 看起来没反应 | 按 L **整座相连的桥一起塌** |
| 大炮能不能调方向 / 子弹数 / 马里奥和我都能钻 | 原来只能朝固定方向、炮弹 1 发、只有你能钻 | 伪装控制大炮时：**←→ 调炮口左右、↑↓ 调仰角**（金色炮管显示指向），L 开炮；想换别的机关按 **Shift + 方向键**。每门炮炮弹数 = `cannonShotsPerRound`（默认 1，可设任意数，0 = 只能当人肉炮）。**炮弹打完后你和马里奥都能钻进去**：你进炮后可以按方向键调角度；马里奥只在"炮口朝向他的目标且目标 ≥4 格远"时才钻。冷却 `cannonLaunchCooldown` **默认 30 秒**（可配置）。 |
| 想要猎人绳套 | — | 新元素 **绳套 `Y`**：谁踩到谁被倒吊 **10 秒**（`snareSeconds` 可配置）再掉下来——**你自己踩到也会中**（伪装着踩也现形）。伪装在旁按 L = 重新装好 / 提前放人。头顶必须空 2 格（工坊会检查）。 |

## 2. 涌现与反转：本次加的
**随机道具箱 `?`**（参考 Mario Kart 道具箱：规则是"谁拿到谁用"，只借规则）：
- 每局在所有 `?` 道具点里随机亮 `pickupsPerRound`（默认 2）个；**谁先碰到归谁**；
- **同一个箱子给你和给马里奥效果不同**（反转变数）：

| 你捡到 | 马里奥捡到 |
|---|---|
| 💣 +1 炸弹 | ⏳ +1 次时间静止 |
| 🔻 +1 缩小 | 👟 加速 8 秒 |
| 🎯 大炮冷却刷新 | 🛡 护盾（下一次被坑免疫） |
| 👻 隐身 8 秒（站着不动时他看不见） | 👁 透视 ~5 秒（看穿伪装） |

- H4：马里奥不会专门去找箱子，只是"路过碰到"；透视/隐身都走他自己的感知通道。
- 箱庭样板里放了 4 个道具点、1 个绳套。

## 3. 连锁（现在已经能自然发生的）
- 炸弹 → 炸开裂缝地板 → 马里奥掉下去 → 落进毒池（连招 + 地形）
- 炸弹炸掉你脚下的地面 → 你掉下去躲开时间静止
- 大炮把你打飞 → 撞碎裂墙（高速撞击）
- 绳套吊住马里奥 10 秒 → 你有时间跑到大炮旁瞄准他
- 他捡到透视 → 你的伪装失效 → 只能靠通风管/缩小逃
