## 连锁示例（箱庭样板里已经摆好）
- **看守所**：喷火旁一个油桶 → 你按 L 喷火 → 油桶 0.8 秒后爆炸 → 炸开地面让出口前多一个洞。
- **牢房区**：火 + 油桶紧挨着 → 马里奥路过时点火，爆炸把他炸晕（-1 血）→ 接塌桥。
- **金库**：油桶在两门大炮之间 → 用大炮打中油桶，远程引爆。
- **放风场**：铁笼在弹簧板前 → 关住他 3 秒 → 你钻通风管去下一层埋伏。

## 规则保障
- H4：诱饵走马里奥**同一个视锥与遮挡**规则；警报是公开的环境状态；踢门只看他自己的位置和目标。测试 `MindAndDriverNeverReadTricksterTruth` 仍然通过（禁止读取附身/伪装内部状态）。
- H9：铁笼、绳套都必然放人；油桶和炸弹只会多开路；最外圈与最底层不可炸。
- 死局检查：油桶按实心（不炸）算；铁笼/诱饵不影响地形。
