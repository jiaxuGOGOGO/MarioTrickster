# S203：马里奥性格——冲冲型 / 谨慎型 / 贪财型

每局开始按种子随机一种（三种等概率，可调权重、可固定），**开局 3 秒头顶大字亮出来**，之后头顶意图前面一直带性格名（如"谨慎型·绕开"），屏幕还会提示这局该怎么坑他（H6：看得懂才能针对）。

| 性格 | 赶路 | 被坑过的地方 | 道具箱 | 起疑 | 怎么坑他 |
|---|---|---|---|---|---|
| ⚡ **冲冲型**（原来的） | 正常 | 路过时放慢（S200 学习层） | 同层 4 格内顺路捡 | 正常 | 什么都行 |
| 🛡 **谨慎型** | 慢 10% | **绕开**：寻路把被坑点周围 2 格设为禁区，找一条经过别的高度的路；**绕不开就跳过去**；再不行才硬走（不会停住） | **不绕路捡** | 快 25% | 同一个坑用不了第二次 → 布新连锁；他绕路走的是**另一条路**，那边也要有坑 |
| 💰 **贪财型** | 正常 | **不长记性**（不放慢、不绕） | **一定去抢**：14 格内看得见的都去，**跨楼层也去**（按楼层寻路走过去），5 秒够不着才放弃 | 慢 10%，抢道具时再减半 | 在道具箱旁边布连锁 = 必中；但他抢到护盾/加速/透视会反过来克你 |

## 规则保障
- H4：性格只改变他**自己**的走法和反应；感知仍只有看（同视锥）、听（只有位置）、记（自己被坑过的位置）。
- H1/H10：谨慎型绕路只在"真有另一条路"时才走（同层原地跳的走法不算，AI 执行不了）；绕不开 → 跳 → 原路。刚被坑的脚下那格不算禁区（避免原地卡住）。贪财型有放弃计时。
- **自动检查（Hands-off / Trap Probe）会轮流测三种性格**（第 1 局冲冲、第 2 局谨慎、第 3 局贪财…），每局结果标出性格，CSV 多一列 `personality`；试玩记录也多一列。

## 样板变化
- **诱捕走廊**加了一条上方"高路"（连续单向台面 + 入口台阶）：谨慎型被坑后会走高路绕开地面陷阱 → 你要么在高路尽头埋伏，要么把他引下来。

## 可调（RushMarioTuning，dataVersion 14）
`personalitiesEnabled`、`fixedPersonality`（-1 随机 / 0 冲冲 / 1 谨慎 / 2 贪财，想专门练某种时用）、`rushWeight` `cautiousWeight` `greedyWeight`、`personalityIntroSeconds`、`cautiousTypeSpeedScale` `cautiousTypeSuspicionScale` `avoidRadius`、`greedyPickupDetourCells` `greedyGiveUpSeconds` `greedySuspicionScale`、`autoCheckCyclePersonalities`。

## 参考（只借规则）
吃豆人的四只鬼各有性格（追击 / 埋伏 / 多变 / 随性），设计者岩谷彻用这种方式避免游戏"太难或太无聊"，玩家要读对手而不是背路线（[Wikipedia: Ghosts (Pac-Man)](https://en.wikipedia.org/wiki/Ghosts_(Pac-Man))）。
