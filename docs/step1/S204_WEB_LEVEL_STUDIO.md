# S204：网页关卡设计台——在网页上想清楚，再交给 AI 实现

用户需求："在一个网站上设计关卡、构思新机制、删减旧东西，规划清楚后再来这里提出完整的关卡意见进行更新"。

## 做了什么
- `tools/LevelStudioWeb/index.html`：**单文件网页**，双击打开，离线可用，自动保存到浏览器。
  - **画关卡**：全部 44 个元素（默认只显示第 1 步能用的 30 个），4 个样板，画笔/矩形/填充/吸管/撤销，Alt+点击写批注。
  - **实时预检**（移植自项目 C#，同一套数字）：摆放规则（脚下实心、弹簧头顶 4 格、炮口前 3 格、毒池 ≤3、绳套/铁笼头顶 2 格、通风管成对、唯一元素）、边界、M/T/G/o 各一个、**死局检查**（塌桥/裂缝/捷径门/裂墙全开后能不能回出口，L2 可达性同规则，红斜线标格子）、**马里奥路线 + 时间线**（几秒走到哪个机关、离路线太远的机关）。四个样板结果与 Unity 一致，箱庭 63 毫秒算完。
  - **新机制提案**：字符/名字/类型/颜色/属性 + 做什么/预警/代价/反制/摆法/能连什么；按属性自动提醒要说清的宪法条款（H1/H3/H4/H6/H9/A2）；提案进元素库可直接画；"想删改的旧东西"清单。
  - **交给 AI**：一键复制/下载"设计单"（markdown）：关卡 ASCII、意图、时间线、预检问题、批注、提案（缺什么规则说明）、删改项；也可只导出 .txt。
- `build.py`：从 `AsciiElementRegistry` + `ElementCatalog` + 样板源码生成网页（单一来源，元素改了重跑即可）。
- Unity 工坊"导入"支持网页导出的 `.studio.json`（`LevelWorkshopModel.GridFromStudioJson`；未实现的提案字符先换空气并提示）。测试 +1。

## 工作流
1. 双击网页 → 载入样板或空白房间 → 画、写批注、写新机制提案、勾选想删改的东西。
2. "交给 AI" → 复制设计单 → 发给 Genspark AI："按这份设计单更新 MarioTrickster"（附上接续包）。
3. AI 按接续包规则实现、跑完整体检、交付升级包；网页随之重建（新机制变成正式元素）。

## 边界（诚实说明）
网页只做快速预检；炸弹困人模拟、三种性格自动检查、陷阱试探、真实物理手感只在 Unity / AI 体检里。网页说"可以交给 AI 试玩"≠ 最终通过。
