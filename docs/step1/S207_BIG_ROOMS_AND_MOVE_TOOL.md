# S207 大房间镜头（死亡细胞式）+ 设计台移动工具 + 吸管/勾选框更好懂

## 用户反馈
1. 摆好的关卡道具不能点击移动。
2. 吸管不明确、不方便。
3. 画面上方的勾选框看不懂"影响是啥"。
4. 关卡往前延伸时，希望像《死亡细胞》那样镜头跟着人走，不局限于一个小框；不要破坏游戏规则、不要留连锁隐患。

## 做了什么
### 游戏里（Unity）
| 改动 | 说明 |
|---|---|
| 新镜头模式 **智能跟随**（`Step1CameraMode.SmartFollow`，追加在枚举末尾） | 平时一屏 12 格高、朝移动方向多看 3 格；上下有 1.5 格死区（小跳不晃镜头）；马里奥离你 ≤16 格时自动拉远把两人都框进来（最多 18 格高）；离得远就只跟你。镜头不看出房间外。 |
| 自动选择 | 房间 **宽 >64 或 高 >16** → 开局自动用智能跟随（以前只看高度，宽房间会缩成一个小框——这就是"局限在小框里"的原因）。默认 48 宽房间不变。按 **C** 可在 整个房间 / 框住两人 / 只跟你 / 智能跟随 之间切换，屏幕会提示当前模式。 |
| **屏外红箭头**（`Step1OffscreenMarkers`） | 马里奥在屏幕外时，屏幕边缘红箭头指着他，带头顶同款符号 ? ! !! ?!（H6 同一含义）和距离；宝物/出口在屏外时也有小箭头。 |
| **小地图**（`Step1MiniMap`） | 大房间时右上角显示整张图：你、马里奥、宝物、出口 + 当前镜头框。按 M/Tab 看图例时小地图放大。 |
| 回合时间按路线放宽 | 构建时估算马里奥走一趟的秒数：回合时间 = max(150, 一趟×3)；自动检查超时 = max(70, 一趟×2+20)。默认房间一趟 ≈20 秒 → 仍是 150/70 不变；长关卡不会"还没走到就超时/被误判卡住"。 |
| 新样板 **长廊远征**（94×15） | 工坊工具条"样板：长廊远征"；两段诱捕走廊连起来，后半段换成黏胶。模拟：一趟约 39 秒，炸弹困不住（自动加固）。 |

安全边界：新箭头/小地图只给玩家看，马里奥 AI 一侧代码不读它们（H4，测试检查）；自动检查、连锁回放、帮助页打开时不画。调参新字段有 `dataVersion 15` 升级块，旧资产自动补默认值；构建器版本 17→18（重新构建场景会自动带上新组件）。

**最大尺寸仍是 128×48**：实测 186 宽时一次模拟 30 多秒且炸弹加固失败，232 宽约 50 秒也失败——再大既卡又不稳。想做更长的旅程，后续用"多个房间连起来"（章节/连廊）而不是一张超大图。

### 关卡设计台（网页 + Unity 工坊，同一套规则）
| 改动 | 网页 | Unity 工坊 |
|---|---|---|
| **移动工具** | 按钮"移动" / 快捷键 **V** | 工具"移动" / 快捷键 **M** |
| 用法 | 点住已放的东西拖走（连成一片的同种一起走，比如整座塌桥）；空白处拖 = 框选；方向键挪 1 格；Del 删除；Ctrl+C 复制、鼠标放到目标处 Ctrl+V 粘贴；Esc 取消 | 同左 |
| 保护 | 外圈墙不动也不会被盖掉；马里奥/捣蛋者/宝物/出口只能搬、不复制、不会被盖掉或删掉 | 同左 |
| **吸管** | 点一下 → 画笔变成它 → **自动回到原来的工具**，并弹提示"画笔换成了什么"；随时 **Ctrl+点击**（或鼠标中键）直接吸，不用切工具 | 吸完弹提示并回到画笔；Alt+点 = 吸取 |
| **显示勾选框** | 归到"显示（只改画面）"一组：只改变画面显示，**不改关卡、不影响检查、不影响导出**。每个勾选框前有颜色小块，鼠标停上去有一句话解释 | — |
| 最坏情况预览 | 勾上时顶部出现黄色横条说明"这只是预览，不能画"，此时点画布不会改图 | — |
| **游戏一屏** | 新勾选框：蓝色虚线框 = 游戏里镜头一次能看到的范围（跟着鼠标走） | — |
| 状态栏 | 显示"现在点画布会发生什么" | 同左 |

## 快捷键变化
- 网页：新增 V（移动）、Ctrl+点击（吸管）。Alt+点击仍是写批注。
- 工坊：新增 M（移动）。
- 游戏：C 切镜头（原有）现在有 4 种并提示当前模式。
