# S208：不知道从何下手？——新建关卡向导 + 模式印章 + 节奏条 + 转移点提示

## 一句话
打开设计台 → **＋ 新关卡（向导）** → 写一句话点子、选主角机关、选时长 → 得到一张**已经能玩**、按"起承转合"4 段摆好的草稿。然后只改最别扭的一处，试玩，再改。

## 调研：这是不是最该做的升级？（结论：是，但改了两处）

## 新东西
| 名字 | 在哪 | 怎么用 | 规则 |
|---|---|---|---|
| 新建关卡向导 | 网页"＋ 新关卡（向导）"（第一次打开自动弹）；Unity 工坊工具条"向导…" | 点子（可空）→ 主角机关（火/香蕉皮/封路墙/弹簧/绳套/铁笼/大炮/塌桥）→ 20/30/40 秒（48/64/94 宽） | 生成的 24 种草稿全部通过死局检查 + 炸弹策略模拟；节奏无提醒；每个机关旁都有地方躲 |
| 模式印章 | 网页左栏"模式印章" + 工具 S；工坊"印章 ▾" | 选一个 → 鼠标放在马里奥站的那格（看预览）→ 点 | 不动外圈，不覆盖 M/T/G/o；每个印章单独盖在空房间里都可玩 |
| 起承转合分段 | 网页显示组；工坊"起承转合"开关 | 金色虚线 4 段；向导建的关按向导分段，其他关按 M → 宝物平均切 | 只改画面 |
| 节奏条 | 网页右栏；工坊状态区一行 | 红 = 马里奥经过机关（前后 1 秒，去程 + 回程都算），绿 = 喘气 | 连续红 ≥8 秒 / 连续绿 ≥10 秒（开局 4 秒等待不算）→ 提醒 |
| 转移点提示 | 网页显示组（橙圈）；工坊橙框 | 机关 5 格内没有草丛 b / 箱子 c / 油桶 U / 随机槽 1 2 / 隔墙 → 提示"提前伪装好等他来，或旁边放一丛草" | 只提示，不拦 |

## 8 个印章（`LevelBlueprint.Patterns` = 网页 `PATTERNS`，同一份数据）
| 印章 | 摆法（`*` = 主角机关） | 考验 |

## 规则保障
- H1/H9：向导草稿与印章都走完整检查；verify.sh 对 24 个草稿跑死局 + 炸弹策略模拟，8 个印章单独盖章检查。
- H4：这些都只在编辑器里（给设计者看），马里奥 AI 代码一行没改。
- 网页 = Unity：同名函数、同一份印章数据（EditMode 测试逐字对照）；verify.sh 用 node 跑网页 `wizardLevel` 生成 24 张草稿，与 C# `LevelBlueprint.Wizard` 逐字比较（0 差异）。
- 不改任何游戏数值（dataVersion / BuilderVersion 不变）。

## 下一步（建议）
1. 用向导做 3 关（不同主角机关），各玩 3 局，只改最别扭的一处。
2. 把"自己最常用的一小段"告诉 AI → 加成你自己的印章。
3. 以后做多房间连廊时，向导可以一次生成"一栋楼的 4 个房间"（每个房间一个节拍）。
