# S209：试玩截图修复——马里奥在台边徘徊 / 捣蛋者粘在墙上

截图位置：样板 **地下监狱·四层** 最底层右端（宝物 Star Fragment 旁）。

## 问题 1：马里奥在宝物正上方左右徘徊，拿不到也走不开
**为什么**
- 宝物在一段单向台面（浅蓝短条）的**右边缘正下方**。
- 马里奥 AI 的规则是"离目标左右不到 0.3 格就停下"。他走到台边、对准宝物，就停了——可是他身体有 0.8 格宽，还有一半踩在台上，**掉不下去**。于是原地抖。
- 6 秒后"卡住救援"把他挪到"最近的安全位置"= 就在台子旁边，他又走回台边，**循环**（截图上方那条黄字）。
- 以前的死局检查只算"理论上走得到"，所以关卡检查是绿的。

**怎么修**
| 修了什么 | 效果 |
|---|---|
| 新转向规则：目标在**脚下更低处**时，继续朝目标那边走，直到走下台边；已经在空中就不再推 | 他会从台边走下去，直直落到宝物上 |
| 卡住救援改成**沿他要走的路线往前放**（越过卡住的地方 ≥2 格，而且必须能到出口） | 真卡住时也不会再被放回原地循环 |
| 新检查"按马里奥的走法走一遍"：按他真实的身体宽度和同一条转向规则，从出生点→宝物→出口走一遍 | 工坊完整检查里出现黄色提示"按马里奥的走法走一遍：去拿宝时停在 (x,y)" |

**影响范围**：用旧规则走一遍，59 关里有 **31 关**会卡住（地下监狱样板 + 所有监狱塔的楼梯口）。新规则 **59 关全部走完**。这不是一关的问题，是 AI 走法的问题，所以修在 AI 上，不去挪关卡。

## 问题 2：捣蛋者跳到墙边就粘在半空不掉
**为什么**
1. 以前（S198）修过"贴墙不粘"，但判断放在了"读方向键"**之前**——判断完把朝墙速度清零，紧接着方向键又把速度加回去 → 修复没生效。
2. 伪装后身体从 0.8 格变成 1.2 格，而且是**从中心往四周变大**。在墙边或贴地变身时，身体直接**长进墙里/地里**。脚下检测把"墙里那一格方块的顶面"当成了地面 → 悬在半空。

**怎么修**
| 修了什么 | 效果 |
|---|---|
| "贴墙不粘"挪到方向键**之后**判断 | 空中贴墙按着方向键也会正常落下 |
| 伪装变大时**脚底不动**，只往上长 | 贴地变身不会陷进地里 |
| 新增"嵌墙自动推出"：身体和墙重叠 → 每帧最多推出 0.5 格（单向台面不算） | 任何原因嵌进墙（变身、缩小恢复、传送）都会被推出来；马里奥也有 |

## 规则保障
- H1/H9：新增走一遍检查；救援沿路线且必须能到出口。
- H4：转向、救援只用地形和马里奥自己的目标；推出墙是纯物理，不读对手信息。
- H10：新规则只会让他"多走半步下台边"，不会让他停住。
- 不改任何游戏数值，**不用重建恶作剧房间**。

## 你怎么确认修好了
1. 工坊 → 样板 → 地下监狱·四层 → 试玩：马里奥到最底层右端会从台边走下去拿宝，不再徘徊、不再出现"卡住"黄字。
2. 控制捣蛋者跳到墙边、贴着墙按方向键：会正常掉下来；在墙边按 P 伪装：不会悬空。
