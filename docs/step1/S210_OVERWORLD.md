# S210：星露谷视角小镇（大地图）

## 一句话
以前只有"一个横版房间"。现在外面多了一张**俯视的小镇**：马里奥每天按时间表去几户人家，**每户人家的门里就是一个横版房间**（你以前做的关卡、样板都能连进去）。你要在小镇上抢时间，抄近路先到门口埋伏。

## 为什么这样做（调研）
| 参考 | 学到什么 | 用在哪 |
|---|---|---|
| [星露谷地图格式](https://stardewvalleywiki.com/Modding:Maps) | 地图分层：地面 / 建筑 / 盖在人上面的一层（树冠、高草）；门 = 传送点 | 树冠和高草会盖住你；门 1–9 连房间 |
| [星露谷一天](https://stardewvalleywiki.com/Day_Cycle) | 时钟推着人走，NPC 按日程出门 | 马里奥按门上的时间去，右上角时钟 |
| [塞尔达 II](https://zelda.fandom.com/wiki/Zelda_II:_The_Adventure_of_Link) | 俯视大地图 + 进入后是横版区域 | 小镇俯视、门里横版，横版房间规则一点不变 |
| [潜行设计](https://gamedesignskills.com/game-design/stealth/)、[Gamedeveloper](https://www.gamedeveloper.com/design/stealth-game-design) | 看得见的视锥、掩体、分级警戒 | 地上画出他的视野；高草/树/房子挡视线；和房间同一套 ? → ! → !! |

**关键决定**：小镇不是第二套战斗，是"抢时间、选埋伏点"的前奏。真正的恶作剧还在房间里，设计宪法 H1–H10 全部照旧。

## 怎么玩（小镇上）
| 键 | 作用 |
|---|---|
| 方向键 / WASD | 走（你比他快：5 格/秒 vs 3.4） |
| P | 伪装成木箱（站着不动他不怀疑；伪装着乱动 = 可疑，还走得慢） |
| L | 让 3 格内的香蕉皮变滑：闪 0.5 秒 → 滑 3 秒，他踩到晕 1.5 秒 |
| T | 挑衅：把他引过来（每天 3 次） |
| E | 在门口按：**比他先到 = 埋伏**（进屋开打，还多 1 枚炸弹）；**他进门 6 秒内 = 迟到**（照样打，但他不等你直接冲）；再晚 = 这户被偷 |
| H | 说明 |

- 高草里：只有贴身 1.5 格才看得见你，但你在草里走动会晃，他看见就起疑。
- 19:00 以后是晚上：他只看得见 3.5 格，**路灯下除外**。
- `?` 道具箱：捡到 +1 炸弹，带进下一个房间（最多 +3）。
- 被他抓到：送回出生点、定身 3 秒（不扣命，代价是错过埋伏）。
- 一天结束：守住一半以上的门 = 你赢。按 R 再来一天。

## 怎么做小镇
**Unity**：菜单 MarioTrickster → Town Workshop（**Ctrl+Alt+O**），或关卡工坊工具条的"🏘 小镇"。
1. 左边选格子画；门画在房子最下面一排的**下方一格**。
2. 右边给每扇门填时间、选房间（内置样板 + 你关卡库里的所有关卡）。
3. 看检查（红 = 必须改）和"马里奥的一天"（每扇门你能提前几秒到）；画布上红点 = 他的路线。
4. **▶ 试玩小镇**：自动把每个房间做成场景、登记 Build Settings，然后开始。

**网页设计台**：新页"大地图"，功能同上；导出关卡包会带上小镇，Unity 小镇工坊 → 导入（关卡包里的房间也一起进关卡库）。也能导入 Unity 导出的小镇 .txt、或 Tiled/CSV 数字表（在大地图页导入）。

## 规则保障
| 规则 | 怎么保证 |
|---|---|
| H1 一定走得通 | 检查：外圈挡路、家→每扇门、你→每扇门、家↔出生点都连通；每个房间自己也要通过原来的检查 |
| H2 先预兆 | 小镇和房间用同一个起疑表；从小镇带进房间的起疑最多到 '?' |
| H4 只凭看见的 | 马里奥只知道：视锥+距离+遮挡里看见的外观、草晃、挑衅声、踩到香蕉皮（测试检查代码里不读你的内部状态） |
| H9 不会没完没了 | 追最多 8 秒，找 2.5 秒，晕 ≤ 3 秒，然后回到日程 |
| H10 没人捣乱也能过完一天 | 检查按真实身体一步步走一遍，22:00 前必须到家；样板 18:51 到家 |

## 确认结果
沙盒（无 Unity）：运行时 + 编辑器编译通过；151 条测试文字检查通过；样板小镇可玩、4 扇门你都能提前 22–25 秒到；9 组速度/时钟组合都走完一天；拆掉桥的反例会报错；**网页和 Unity 的检查结果逐字一致**。

**没验证、要你在 Unity 里看的**：场景切换（小镇 ↔ 房间）、画面（方块美术，先验证好不好玩）、手感和数值（调参资产里 Overworld 一栏都能改）。
