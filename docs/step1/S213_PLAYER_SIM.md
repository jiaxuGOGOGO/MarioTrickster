# S213 以玩家视角模拟一天，再按结果改

## 怎么模拟的
小镇的规则原来写在游戏脚本里，沙盒跑不了。这次把规则整段搬进一个纯逻辑类（OverworldTown），**游戏和模拟用同一份代码**。然后让 7 种"像真人"的机器人玩家各玩一天。它们只看玩家看得见的东西（地图、时间表、屏幕上的马里奥、箭头）：

| 机器人 | 像哪种玩家 |
|---|---|
| 跟箭头 | 新手：跟着箭头去门口，站着一直按 E |
| 会躲 | 学会规则：到门口按 P 伪装，等他走近再按 E |
| 反应慢 | 出门后愣 1.5 秒才动，走路偶尔停 |
| 贪心 | 先去捡所有道具箱 |
| 捣蛋 | 用香蕉皮拖他 |
| 挂机 | 什么都不按 |
| 乱按 | 随机乱按 100 天，专找卡死 |

房间里的横版战斗没有模拟，进门就记一个"守住"，只看小镇这一层。

## 模拟出来的问题 → 怎么改的
| 问题（改之前） | 改法 | 改之后 |
|---|---|---|
| 直奔门口按 E 就算埋伏：每种玩家 4/4 全胜，躲藏、伪装、香蕉皮都没用 | 他已经出发、离门 **8 格以内**，而且没盯上你（不是 ! / !! / ?!）才算埋伏；门口提示"他还有 N 格" | 会躲的 12/12；站着不躲 6/12；贪心的 3/12 |
| 反应慢的人每次出房间都被抓（5 天 21 次）：出门时两人站在一起，他面朝你 | 他出门先**清点 2.5 秒**（头上"…"，不看不听，面朝门） | 3 天被抓 1 次 |
| 最后一扇门打完还要等他走回家（约 20 秒，路上还会抓你） | 最后一扇门有结果就直接结算 | — |
| 一天约 120 秒，一次最长干等 26–33 秒 | 按住**空格快进 ×4**。只在他平静、离埋伏范围还远时生效，有动静自动停 | 会躲的玩家一天 **53 秒**，最长干等不到 2 秒 |

"8 格"是扫出来的：3–6 格时站着不躲一扇门都埋伏不上（太难），10 格时不躲也全胜（躲藏没意义），8 格正好是"会躲才稳赢"。在 Inspector 调参 `overworldAmbushSteps` 里可以改。

## 规则保障
- 马里奥仍然只靠看和听知道你（H4）；"…"清点状态头上有标记，看得见（H6）。
- 挂机、乱按的每一天都能自己结束（H9 / H10）。
- 这些模拟每次都会跑（verify），以后改规则如果又出现"站着就全胜""出门被秒抓""干等"，会直接报红。
