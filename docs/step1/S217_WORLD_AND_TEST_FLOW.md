# S217：大地图能往外扩 + 运行时"画面不动/控制不了"修复 + 一键测试中心

## 一句话
小镇地图现在能**往四个方向扩大**（最大 192×128，老镇原样保留）；进小镇**不会再卡在说明面板上不动**；新增**测试中心**（Ctrl+Alt+T）：一键体检全项目 → 试玩 → F8 随手截图 → 打包反馈发给 AI，反复测试不再被弹窗和问卷打断。

## 为什么"运行时画面固定不动、控制不了"（根因）
| 原因 | 以前 | 现在 |
|---|---|---|
| 说明面板挡住一切 | 小镇一进来弹说明，**只有按 H 才能关**；开着时时间、走路、马里奥全部停住——看起来就是"画面定住了" | **按任意键关闭**（面板底部写着）；快速测试模式直接不弹 |
| 键盘在别的窗口 | 从小镇工坊点 ▶，键盘焦点还在工坊窗口，游戏收不到按键 | 进 Play **自动切到 Game 窗口**；游戏没焦点时屏幕中间提示"先点一下游戏画面" |
| 有的键只读旧输入系统 | 说明面板"任意键开始"、R 再来一天、结算 R/N、Esc、F5 在部分机器上没反应 | 全部走 `Step1Keys`（新旧两套输入都读） |
| 时间被暂停过 | 从暂停着的房间回小镇，timeScale 可能是 0 | 小镇开场强制 timeScale=1，小镇计时用不受暂停影响的时间 |
| 转场卡住 | 加载出错时黑幕可能一直在 | 20 秒保险丝：强制收起黑幕并记错误 |
| 早上没人动 | 06:00–08:00 马里奥在家不动，看着像"卡了" | 底部提示"马里奥 08:00 才出门去门 1（还有约 30 秒）——先去门口躲好，或按住空格快进" |

另外：头顶挂名字（蓝"你 YOU"、红"马里奥"）；底部常驻按键条；`-` / `=` 拉远拉近镜头（大世界看得更全）。
小镇里你操作的是**捣蛋者**（方向键/WASD），马里奥是 AI 自己走（这是玩法，不是 bug）。

## 大地图往外扩（Unity 小镇工坊 / 网页大地图页，同一套规则）
工具条 **"↔ 扩展 44×28 ▾"**：四周各 +8 / +16、只往东/西/南/北 +16、宽高 ×2、裁掉四周 4 格。
- 往哪边扩，那边原来的围栏树就拆成草地 → 老镇和新地连成一片；新地铺草地；新的最外一圈自动种树（H1：走不出地图）。
- 门、家、出生点、批注跟着平移；老镇里面**一格不变**。裁剪会丢东西时先问你（Ctrl+Z 可撤销）。
- 上限 96×64 → **192×128**。更大的世界请拆成几张小镇（PageUp/PageDown 切换）。
- 画布只画看得见的格子、地面在游戏里是一张贴图 → 最大尺寸也不卡。⤢ 按钮：缩放到整张图都看得见。

## 测试中心（MarioTrickster → 测试中心 Test Hub，Ctrl+Alt+T；小镇工坊工具条 🧪）
1. **① 一键体检**（几秒，不进 Play）：所有横版房间（默认 + 样板 + 关卡库）的可玩检查、所有小镇的检查 + 没人捣乱走一天 + 机器人玩家各玩一天、调参/构建器版本、场景新旧、上次测试结果、反馈数量 → 写进 `PlaytestLogs/HealthCheck.md`。
2. **⚡ 快速测试模式**：不弹玩法说明、房间结束不弹 5 道问卷（直接 R / N）。只改界面打不打断你，不改玩法。
3. **② 试玩小镇 / 房间**：试玩时按 **F8** = 截图 + 自动记下"当时情况"（场景、几点、第几局、马里奥状态、双方位置）。游戏里出的红字错误也**自动记下**。
4. **③ 打包反馈**：体检 + F8 截图 + feedback.md + TestReport.txt + 试玩记录 → `PlaytestLogs/反馈包_日期.zip`，把它发给 AI 即可。

## 刻意没做
- 没改小镇玩法数值、马里奥 AI、房间机关（这次只修"测不动"和"地图不够大"）。
- 没做无缝多区域大世界（跨地图边走边加载）：先用 192×128 单图 + 多张小镇切换验证好不好玩，真要再做。
