# S218 小镇大机关：比房间夸张一个量级 + 连锁 + 天气 + 小镇 ↔ 房间联动 + 总管全局编辑

## 一句话
小镇不再只是"赶路 + 躲草丛"的前奏。现在它有**只属于小镇的夸张机关**（巨炮把人轰过半个镇、滚石一路撞碎木箱栅栏、水塔把路口淹成泥地），机关之间会**连锁**；每天早上**公布天气**，带来可以预判的随机。**小镇和房间互相影响**：在镇上把他砸晕了再进门，他进房间还晕着；守住一户，小镇里的大机关会重新装填。编辑器（Unity 小镇工坊 / 网页大地图页）直接在画布上画出"谁连着谁"，悬停一扇门就能看到门里的房间，不用来回切页面。

## 为什么这样做（第一性原理 + 调研）
| 问题 | 结论 | 依据 |
|---|---|---|
| 小镇道具要不要"比室内更夸张"？ | 要，但只夸张**作用范围**（几十格），**不另起一套规则**：巨炮就是"把人送去另一个地方"，滚石就是"一路推开东西"，水塔就是"改地面"。玩家只学一次 | BotW 化学引擎三条规则：元素改变材质、元素互相改变、材质之间不互相影响（[GDC 2017 报道](https://www.thumbsticks.com/gdc-17-breath-of-the-wild-science-lies/)）；先在小沙盒里验证"乘法"（[同场演讲](https://www.thumbsticks.com/gdc-17-breaking-conventions-breath-of-the-wild/)） |
| 随机放在哪？ | **只放在做决定之前**：天气 06:00 公布、整天不变；机关一旦发动，结果完全可预判（炮口、落点、滚道编辑器里和游戏里都画出来） | Keith Burgun：输入随机可以、输出随机要避免（[Game Developer](https://www.gamedeveloper.com/design/randomness-and-game-design)）；Into the Breach"所有攻击都显示、没有命中率"（[GDC 2019 PDF](https://media.gdcvault.com/gdc2019/presentations/Into%20the%20Breach%20Postmortem%20Final.pdf)）；Sid Meier：随机让玩家起疑心，坑人要能看出原因（[Game Developer](https://www.gamedeveloper.com/game-platforms/gdc-sid-meier-s-lessons-on-gamer-psychology)） |
| 涌现从哪来？ | 机关**互相引爆**（冲击 1.5 格内震响下一个）+ **天气改参数**（风吹偏炮弹、雨让水更大）+ **马里奥会学**（吃过亏就躲）。三者相乘，每天的局面都不一样 | Into the Breach：操纵敌人撞别的威胁比直接打死好玩（[复盘视频](https://www.youtube.com/watch?v=s_I07Iq_2XM)）；Noita：涌现有"酷"也有"毁游戏"两种（[GDC 2019](https://www.youtube.com/watch?v=prXuyMCgbTc)） |
| 会改地形的机关会不会造成死局？ | **只会"打开"，不会"关死"**：滚石撞碎木箱/栅栏、水塔把地变泥（都还能走）；最外一圈永远不动；改掉的地形只活一天。检查会算"炮弹落点走不走得回家" | Noita：玩家会把自己永久卡死（同上）；Mario Maker：作者必须能通关、不许初见杀（[Game Developer](https://www.gamedeveloper.com/design/lessons-of-game-design-learned-from-super-mario-maker)） |
| 大地图怎么不变成"空旷的清单地图"？ | 危险区密集（门口、大路、广场）、中间留出观察空地；每个大机关**每天都能再用**（每天一次，天气不同结果不同） | Untitled Goose Game GDC：密集危险区 + 周围空地，进进出出就是节奏（[GDC 2021](https://www.youtube.com/watch?v=tA-64QuWgLk)）；开放世界的空间浪费（[MegaBearsFan](http://www.megabearsfan.net/post/2016/07/18/How-open-world-games-fail-to-use-space.aspx)） |
| 小镇和房间怎么联动？ | 两条"看得见的因果"：① 镇上砸晕 → 进门他还晕着（房间开局多等 2 秒，有字幕）；② 守住一户 → 那户旁边用过的巨炮/水塔重新装填 | Level Design Book：捷径 / 门的状态由全局管理（[Gates](https://book.leveldesignbook.com/process/layout/typology/gates)、[Doors](https://book.leveldesignbook.com/process/scripting/doors)）；Hitman：玩家行为跨区域生效（[noclip](https://www.youtube.com/watch?v=sQ0LlNfr8ZI)） |
| 编辑时"来回点选看"怎么解决？ | 画布直接画关系线（炮 → 靶心 + 大风可能的落点、滚道、淹没范围、连锁黄线）；右边"⚡ 大机关 · 连锁"点一行就定位；**悬停门 = 弹出门里房间的缩略图**；天气 7 天预览 | Tiled worlds：邻图一起显示、切换不丢视角（[文档](https://doc.mapeditor.org/en/stable/manual/worlds/)）；LDtk 的痛点：一次只能动一个关卡、不能跨关卡复制（[#1160](https://github.com/deepnight/ldtk/issues/1160)、[#712](https://github.com/deepnight/ldtk/issues/712)）；Bombers' Notebook 式日程（[Wiki](https://zelda.fandom.com/wiki/Bombers%27_Notebook)） |

**质疑后没做的**（避免矫枉过正）：
- 调研里有人提议的"牛群踩踏 / 全镇停电 / 拨钟楼"：牛群需要新的群体 AI，停电和拨钟改的是马里奥的日程规则，这两样都会把"一张表就能读懂的规则"撑破。等这 3 个大机关玩出手感再说。
- 不做真实物理和流体（Noita 的教训：模拟越复杂越不一定好玩）。
- 不做隐藏的保底随机（XCOM 式）。天气完全公开，同一张图的第 N 天永远一样。

## 新格子（小镇专用，和房间字符表分开）
| 字符 | 名字 | 怎么用 | 预警（H3） | 马里奥怎么反制（H4） | 连锁 |
|---|---|---|---|---|---|
| `K` | 巨炮 | 3 格内按 L | 炮口前 3 格闪红 1.2 秒，靶心也闪；轰隆声 14 格内听得见 | 听见 → `?` 停下看；**被轰过一次** → 以后看见炮口在闪会闪出炮口（最多 4 步） | 炮弹落地冲击震响靶心 1.5 格内的大机关 |
| `X` | 靶心 | 和巨炮同一行 / 列 | 地上的红圈，谁都看得见 | —— | 落点 = 冲击点 |
| `O` | 滚石 | 3 格内按 L（往离开你的方向滚） | 晃 1.2 秒，滚道闪红；隆隆声 | 被碾过一次就会躲开滚道 | 滚到头的冲击震响下一个；沿路撞碎木箱 / 栅栏 |
| `U` | 水塔 | 3 格内按 L | 吱呀 1.2 秒，淹没范围显示蓝色 | 泥地谁走都慢（公平），不伤人 | 泡到的香蕉皮自己变滑 |

- 每个大机关每天只能用一次（规则："每种优势都有代价"）。**你自己站进炮口 = 飞过去抄近路**；被自己的滚石碾到你也晕 2 秒；水塔会冲掉高草，也就是你的藏身处。
- 一张小镇最多 12 个大机关（Deception 的"最多同时 3 个"是同一思路：太多了看不清谁连着谁）。

## 天气（每天 06:00 公布）
| 天气 | 影响 |
|---|---|
| ☀ 晴天 | 照常（第 1 天永远晴，先学规则） |
| 🌬 大风（往某边吹） | 巨炮落点往风向偏 3 格（编辑器里 4 个方向的偏移落点都画成虚框，检查保证每个都走得回家） |
| 🌧 雨天 | 水塔淹没半径 3 → 4；香蕉皮滑 3 秒 → 4.5 秒 |
| 🌫 雾天 | 他只看得见平时的 6 成远 |
| 🧺 赶集日 | 他每扇门晚 0–30 分钟出门（仍按顺序、每扇相差 ≥15 分钟、≤20:00） |

按 R 开始新的一天 = 第 N+1 天，天气换一种。天气由"地图名 + 第几天"算出来，C# 和网页用同一个整数哈希，保证逐字一致。

## 规则保障
- **H1**：地形只会打开（撞碎 / 变泥），最外圈不动；检查报红："巨炮落点（含 4 个风向）走不回家"。sim 验证"所有大机关同时发动后仍可玩、一天走得完"。
- **H2**：声音只让起疑值 +35（`?`），走的还是同一个起疑表，不会一声就 `!`。
- **H3**：1.2 秒预警，危险格可见；预警期间不伤人（测试里断言）。
- **H4**：他躲机关只凭两样：①看得见的预警 ②自己吃过的亏（`MarioWary`）。第一次见到巨炮的马里奥不会躲（sim 验证）。
- **H6**：每个效果都有画面：闪红格、抖动、冲击环（环的大小 = 真实连锁范围）、震屏、字幕。
- **H9**：晕 ≤ 3 秒；滚石 / 炮弹都有终点。
- **H10**：机器人 4 种 × 3 天（天气不同），一天全部都能结束；"会躲"的玩家每扇门都埋伏上（12/12）。

## 怎么试
1. Unity：小镇工坊（Ctrl+Alt+O）→ 样板 ▾ → **星露大镇** → 右边"⚡ 大机关 · 连锁"点一行，画布上会定位并看到关系线 → ▶ 试玩小镇。
2. 8:00 马里奥出门，走大路过桥往东。你站到巨炮 K(26,16) 旁边，等他走进红格就按 L：他会被轰进南边菜园的靶心，冲击震响滚石，滚石一路撞碎木箱滚到水塔，水塔把那片淹掉（3 连）。
3. 趁他晕着先去门口按 E：进房间时他还晕着（屏幕上方有字幕）。
4. 网页：大地图页 → 载入样板… → 星露大镇。鼠标悬停门 1–4 能看到门里的房间。

## 下一步（等你试玩反馈再定）
1. 大机关的手感：飞行时间、晕多久、滚速。F8 记下"太快 / 太慢"就行。
2. 房间 → 小镇的第二条联动：房间里的某个机关（比如大炮 K）把他打出窗户，落在小镇的某一格。
3. 第 4 种大机关提案：钟楼（敲钟 = 全镇 `?`，所有人停下看一眼），需要你先觉得前 3 种好玩。
