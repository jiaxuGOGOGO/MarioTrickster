# S219 巨炮能坐能瞄 + 山脉 / 山丘 / 山洞 + 雷雨闪电 / 酸雨 / 泥石流

## 一句话
- **巨炮能坐进去自己瞄**：你和马里奥都可以坐。走到炮旁按 E 坐进去，用方向键瞄准，落点会实时画在地上，按 L 发射。
- **马里奥也会坐炮抄近路**：他坐在炮里瞄准时，地上会出现红圈标出他的落点。你跑过去按 L 能把炮管拨歪，他会飞错地方，落地后晕倒。
- **小镇有了山**：
  - 山丘能挡住平地上的视线（可以躲在后面），站上山丘又能看得更远。
  - 山挡路。
  - 山洞两个一对，是你的秘密近道。
- **天气按地图格局来**：
  - 有路灯的图才会下雷雨，雷雨天可以在路灯旁召唤闪电。
  - 有山洞的图才会下酸雨，酸雨天高草全枯，只剩山洞能躲。
  - 下雨天，冲击震到山坡就会引发泥石流。

## 为什么这样做（第一性原理 + 调研）
| 问题 | 结论 | 依据 |
|---|---|---|
| 大炮要不要能调方向？ | 要。**方向和落点在发射前画出来**，这样才是"你决定的"，不是碰运气。按键用"一下一步"，不用长按转圈：顺着炮管按 = 打远，反着按 = 打近，横着按 = 转向 | Donkey Kong Country 的炮桶分三类：自动发射、按键发射、先瞄准再发射。第三类让玩家自己瞄（[DK Wiki](https://donkeykong.fandom.com/wiki/Barrel_Cannon)）。Into the Breach 把每个攻击的落点都画出来（[GDC 2019](https://media.gdcvault.com/gdc2019/presentations/Into%20the%20Breach%20Postmortem%20Final.pdf)） |
| 马里奥也能坐吗？ | 能，但**只用他看得见的东西**（炮、地图、门）来判断，要省 ≥10 格路才坐。他瞄准要 1.6 秒，落点红圈一直亮着。这是**你的反制窗口**：跑过去按 L 拨歪炮管，他就飞错地方、落地晕倒，**以后再也不坐**（他自己的经历，H4） | 宪法 A2：每种优势都要有反制。Shadow Tactics：敌人行为要"可预测、可观察"，玩家才能玩出花样（[Game Developer 深度剖析](https://www.gamedeveloper.com/design/game-design-deep-dive-dynamic-detection-in-i-shadow-tactics-i-)） |
| 能不能把人打进死角？ | **不能**。落点走不回马里奥的家 = 红叉，不许发射（H1）。坐太久（6 秒）会自动发射；落点不行就把你放下来（H9） | S218 就有的"落点走不回家 = 红色错误"，现在改成实时判断 |
| 山怎么加才不破坏"一张表读懂"？ | 只加**一条规则：高度**（地面 0 / 山丘 1 / 山 2）。中间比两个人都高 → 看不见。所以：躲在山丘后面他看不见你；你站上山丘就看得过去，但他也看得见你；站在山丘上，L 的范围多 1 格（代价：你被远远看见，走得也慢） | Shadow Tactics：高物体完全挡视线，中等高度的能被"探头"看过去（[渲染分析](https://kosmonautblog.wordpress.com/2017/01/09/shadow-tactics-rendering-breakdown/)）。高地的视野要画清楚，否则玩家分不清（同上 Game Developer） |
| 山洞干什么用？ | 当"秘密近道"：两个一对，按 E 从另一头钻出来。**马里奥不走隧道**（他不知道这条路）；站在洞里只有贴身才看得见你 | Level Design Book：捷径是给已经懂地图的玩家的奖励（[Gates](https://book.leveldesignbook.com/process/layout/typology/gates)） |
| 闪电怎么做才不"随机坑人"？ | **召唤闪电**：雷雨天在路灯旁按 L，路灯吸引闪电（先闪 1.2 秒），1.5 格内的人都晕。闪电不会随机劈人 | BotW 的雷暴会随机劈带金属的人，玩家吐槽"被困 15 小时不敢出门"（[ResetEra](https://www.resetera.com/threads/never-ending-thunderstorm-in-breath-of-the-wild.2457/)）。Don't Starve 的避雷针"把闪电引到一个固定点"，玩家有办法控制（[Wiki](https://dontstarve.wiki.gg/wiki/Lightning_Rod/DST)） |
| 酸雨？ | 不伤人（小镇没有血条），**改的是藏身处**：高草全枯一天，马里奥打着伞只看得见 7 成远。你只能靠山洞、树、房子躲 | Don't Starve 酸雨：改变环境和装备，而不是直接扣血（[Wiki](https://dontstarve.wiki.gg/wiki/Acid_Rain)） |
| 泥石流 / 山洪？ | 只在**湿的天**（雨 / 雷雨 / 酸雨）发生，而且必须被**冲击**（炮弹落地 / 滚石撞停 / 闪电 / 水塔）震到挨着山的山丘。泥石流**朝离开山的方向**冲 6 格，路变泥地，冲到的人晕。水塔淹到山坡 = 山洪，不管什么天气都会冲。冲过的地方**只会变泥地（还能走）**，门、家、山洞不改 | Into the Breach 潮汐关：危险格提前标出来，永远不把关键建筑冲断成孤岛（[GameFAQs 攻略](https://gamefaqs.gamespot.com/pc/205477-into-the-breach/faqs/76363/archive-tidal-waves)） |
| 天气池要不要按格局？ | 要。**有路灯才会有雷雨，有 ≥2 个山洞才会有酸雨**。没有这些东西的图，不会出现"用不上的天气"。第 1 天永远晴天，同一张图的第 N 天永远一样 | S218 的输入随机原则（Keith Burgun），加上"天气要能被玩家利用"（Don't Starve 避雷针） |

**质疑后没做的**：
- 山崩改地形（会把路堵死，违反 H1）；火山、地震这类全图随机灾害（输出随机、看不出原因）。
- 雷暴自动随机劈人（BotW 的教训）；酸雨扣血（小镇没有血条，会多出一套系统）。
- 大炮长按连续转动（精度差、会误触），也没有真物理弹道。落点完全由格子决定，网页和 Unity 一模一样。

## 新格子（小镇专用）
| 字符 | 名字 | 规则 |
|---|---|---|
| `^` | 山丘 | 能走（0.75 倍速）。高度 1：挡住两个站在平地的人；站上去看得远、L 远 1 格。挨着山 = 泥石流源头 |
| `A` | 山 | 挡路、挡视线（高度 2） |
| `h` | 山洞 | 能走。站在里面只有贴身才看得见（和高草一样）。两个一对（扫描顺序：从上到下、从左到右），E 钻到另一头 |

## 巨炮新操作
| 谁 | 怎么做 | 画面 | 代价 / 反制 |
|---|---|---|---|
| 你 | 走到炮旁按 **E** 坐进去 → **方向键**瞄（顺着远 / 反着近 / 横着转）→ **L** 发射 / **E** 下来（瞄好的方向留着，以后远程按 L、被连锁震响也打那里） | 绿圈 = 落点、虚线弧 = 弹道、炮管跟着转；红叉 = 走不回家、不能打 | 坐在炮里他只看见一门炮；但你转炮管时 = "伪装的东西在动"，他会起疑（和伪装同一条规则 H6）。6 秒后自动发射 |
| 马里奥 | 省 ≥10 格才去坐。1.6 秒瞄准后发射，自己坐 = 平稳落地 | 红圈 = 他的落点，头上写 AIM | 你在旁边按 **L** → 炮管拨到下一个方向，他落地晕 2 秒，以后不再坐。炮口里有你 = 你也会被轰过去 |

## 规则保障
- **H1**：
  - 瞄准的落点走不回家就不许发射。
  - 泥石流和酸雨只会"打开"地形（变泥地或变草地）。
  - 最坏情况（所有泥石流都冲 + 酸雨）下，检查仍能通过，马里奥一天也走得完。
- **H3**：闪电和泥石流都先预警 1.2 秒，危险格闪红。马里奥的落点红圈要亮 1.6 秒。
- **H4**：
  - 马里奥坐不坐炮，只看公开的炮和地图。
  - 他躲闪只凭自己的经历。
  - 他看不见隧道；你坐在炮里时，他只看得见一门炮。
- **H9**：坐炮有时限；晕倒有上限。
- **H10**：机器人玩家在星露山镇玩 4 天 × 4 种玩法，每天都能结束；会躲的玩家每扇门都能埋伏上。
