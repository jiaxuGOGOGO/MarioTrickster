# S223：马里奥中招反应（S222 总方案 · 阶段 B）

## 一句话
以前他中什么坑都只有一句"被坑晕了"。现在每种坑有一种**固定的样子**：先**愣住**（身体僵住、压扁一下），再做**动作**（往前栽、往后仰、空中转一圈、摇笼子……），最后**恢复**。只改画面，规则一点没动。

## 为什么这么做（来源见 S222_RESEARCH_MASTERPLAN.md §2 F5/F6）
| 来源 | 借来的规则 | 落地 |
|---|---|---|
| Bergson《笑》 | 好笑 = 活人身上出现机械的僵硬 | 第一段"愣住" |
| GDC《Comedy Through Patterns》 | 先建立模式再打破 | 同一种坑永远同一个反应（H6）；打破来自连锁 |
| 动画 take（School of Motion） | 准备—停顿—爆发，笑点在停顿 | 愣住 / 动作 / 恢复三段时长 |
| Reddit"别再滥用顿帧" | 停顿太多 = 拖沓 | 连锁中途再中招：**跳过愣住**直接演 |
| 冲击感 19 特征论文 | 每种打击选几个特征，不全上 | 只动外观的形状/角度/位置，已有的顿帧/震屏/特效不加量 |

## 反应表（`Assets/Resources/MarioReactions.json`，可直接用记事本改）
| 坑 | 愣住 | 动作 | 恢复 | 动作 | 头顶台词 | 本来就晕 |
|---|---|---|---|---|---|---|
| 被烧/刺/炸（hurt） | 0.20 | 0.70 | 0.30 | 手忙脚乱蹦一下 | 哎哟！ | 1.2 秒 |

| 弹簧（launch） | 0.10 | 0.45 | 0.20 | 空中转一圈 | 飞了——！ | 0.6 秒 + 落地 |
| 铁笼（cage） | 0.25 | 1.80 | 0.40 | 摇笼子 | 放我出去！ | 3 秒 |

| 掉坑（pit） | 0 | 0.50 | 0.20 | 左右张望 | 坑？！ | 不晕 |
| 被挡住（stop） | 0 | 0.60 | 0.20 | 跺脚 | 过不去！ | 不晕 |

改数字的规矩：**愣住 + 动作 ≤ 本来就晕的秒数**（sim 自动检查，超了就报红）；不晕的三种整段 ≤ 0.8 秒（边走边演）。写坏了游戏照常，用默认值。

## 规则保障
- H9：反应不延长晕眩；sim 逐项比较"演戏时间 ≤ 晕眩时间"，并做了反向测试（把"被烧到"改成 1.9 秒 → 报红）。
- H4：反应组件只动马里奥的外观节点，不读捣蛋者、不碰速度/碰撞/晕眩（sim + EditMode 双重字符串检查）。
- H6：9 种坑一种一个固定动作和台词；逐帧检查不跳变、最后回原样、左右朝向镜像。
- 旧场景不用重建：进房间时自动挂上（`Step1Combo` 启动时添加 `MarioReactionView`）。
- 每局问卷多一题"有没有被他的反应逗笑？"（Y/N），记进 `step1_rounds.csv` 的 `laughed` 列；旧记录文件自动改名保留。

## 验收（总方案阶段 B）
你关掉快速测试模式玩 **5 局**，每局答"笑了吗"。
- ≥1 局笑了 → 阶段 B 通过，进阶段 C（可读性收尾）。
- 0 局笑 / 觉得拖沓 → **先缩短停顿**（改 json 里的 freeze/act），不加更多特效。

## 刻意没做
新机关、新天气、新性格（总方案冻结横向扩展）；声音（项目还没有音效管线）；小镇大地图上的反应（先在房间里验证好不好笑，再搬过去）。
