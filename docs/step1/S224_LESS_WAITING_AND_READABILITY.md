# S224：少等待 + 看得懂他（总方案阶段 C，跳过试玩先做）

> 用户原话："跳过我试玩的部分继续完成该完成的。我的思路是有些我都没耐心试玩下去，先做得更值得我玩再继续。"

## 一句话
先把**让人玩不下去的等待**砍掉，再把马里奥脑子里已经有的数字**画出来**。规则、数值、AI 判定一行没改。

## 为什么先做"少等待"（实测，不是猜）
用机器人在 4 个样板镇各玩 10 天（手抖模式），统计"连续 10 秒以上什么都做不了"的时间（宪法 P4：死区必须 < 15%）：

| 情况 | 一天用时 | 死区占比 |
|---|---|---|
| 以前·不按空格快进（大多数人不知道要按住空格） | 128 秒 | **81%** |
| S224·不碰键盘 1.5 秒自动快进 | 63–66 秒 | **0%** |

房间里也有等待：开局固定站 4 秒、每局结束 5 道问卷。所以这次一起处理。

| 来源 | 借来的规则 | 落地 |
|---|---|---|
| [Stonemaier：Downtime is a killer](https://stonemaiergames.com/the-top-10-things-i-learned-about-game-design-in-2013/) | 等待杀死游戏；第一局要有"向前的动力" | 自动快进、预约埋伏、Enter 开局 |
| [GameAnalytics：玩家为什么离开](https://www.gameanalytics.com/blog/16-reasons-players-leaving-game) | 两大敌人：无聊和挫败；人们想马上开始 | 同上 |
| [Shadow Tactics 动态侦测](https://www.gamedeveloper.com/design/game-design-deep-dive-dynamic-detection-in-i-shadow-tactics-i-) | 视锥里黄色从眼睛往你这边灌，灌到你 = 被发现；边界要清楚；不要在紧张时暂停打断（他们做过冻结模式，失败） | 视锥灌注；不加暂停 |
| [critpoints：潜行发现机制拆解](https://critpoints.net/2015/03/30/stealth-game-spotting-deconstruction/) | 模糊的值难读，把它映射成"按比例填充的形状"就能读；Mark of the Ninja 把会引来守卫的声音都画出来 | 灌注 + 声音圈 |
| [Radiator：潜行游戏里的失败](https://www.blog.radiator.debacle.us/2015/07/the-systemic-failure-of-stealth-games.html) | 把"被发现"和"失败"分开；"差一点"才是好故事 | 一天结束列"他差点发现你" |
| SpyParty（S222 已读） | 事后告诉玩家他为什么怀疑 | 同上，带原因 |
| [问卷疲劳](https://surveyvista.com/survey-fatigue-fix/) | 1–3 题完成率约 83%；每题要能说出它服务哪个决定 | 问卷**不加题**；"差点被发现"题下面给参考数字 |

## 做了什么

### 少等待
| 地方 | 以前 | 现在 |
|---|---|---|
| 小镇等他出门 | 必须知道"按住空格"才快进，否则干等 | 不碰键盘 1.5 秒**自动快进 ×4**；一碰键盘、他起疑、快到门口、附近有闪电都立刻恢复 |
| 小镇门口埋伏 | 必须掐着时间等他走近再按 E，早按只提示"他还远" | 门口按**一次 E = 预约**，躲着别走开，他一走近自动进门；走开 / 被他盯上就取消 |
| 房间开局 | 固定站 4 秒 | 按 **Enter 马上开始**（开局 0.3 秒后才认，免得关说明那一下误触） |

参数：`MarioMindTuningSO.overworldAutoFastIdleSeconds`（默认 1.5，0 = 关）。数值版本 22 → 23。

### 看得懂他（阶段 C）
| 东西 | 样子 | 和规则的关系 |
|---|---|---|
| 视锥灌注（房间 + 小镇） | 他起疑时，视锥里从眼睛往外灌黄色，越疑越长；认出你变红；墙后面不灌 | 长度 = 视野 × 起疑进度（就是头顶 ? ! 用的同一个数） |
| 声音圈（房间：挑衅 / 炸弹 / 砸墙 / 通风管 / 连锁咔哒；小镇：挑衅 / 大机关） | 从声音的地方扩出一个蓝圈，停在边上淡出 | 圈 = 他真实的听力范围（判定代码直接调用同一个函数）；他在圈里 = 听见了 |
| 他差点发现你（小镇） | 一天结束列出最险的 3 次：几点、起疑到几成、为什么（草晃了 / 路灯下 / 伪装在动…） | 只读他自己的起疑表；被抓的那次不算"差点" |
| 他差点发现你（房间问卷） | "差点被发现"那题下面多一行参考："这局他起疑 N 次，最险一次到 X%" | 只是参考，答案还是你选；**问卷没有加题** |

草晃**不画声音圈**：那是"看见"，不是"听见"（H6：一种信号一种意思）。

## 规则保障
- H4：马里奥侧代码一行没改；声音圈只订阅已有事件来画；sim 检查圈的大小和判定用同一个函数。
- H2/H6：灌注颜色和头顶标记一致（黄 = ?，红 = !）。
- H10：sim 每个样板镇 60 天"会躲 + 自动快进"全埋伏（Wilson 下限 0.940）——自动快进不会让人错过门。
- 反向测试：把自动快进关掉（0 秒），S224 门槛立刻报红（死区回到 81%）。

## 刻意没做
- 没加新机关、新感知、新天气（总方案冻结横向扩展）。
- 没加问卷题（问卷疲劳）；没加暂停 / 慢动作（Shadow Tactics 的失败经验）。
- 没改马里奥速度、视野、晕眩（数值等你玩了再调）。
