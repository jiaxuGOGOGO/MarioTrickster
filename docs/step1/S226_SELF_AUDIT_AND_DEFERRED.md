## 2. E6 交互矩阵（样板房间）

马里奥所有可能的路线都算进去：原路线；打开捷径 / 裂墙 / 裂缝 / 塌桥之后的路线；从每个陷阱处掉下去之后的路线；谨慎型绕开机关的路线。离所有路线都超过 3 格（大炮按射程另加 4 格）的机关，算作浪费。

| 房间 | 只算最短路时碰不到的机关 | 算全部路线后的真浪费 |
|---|---|---|
| Prison | 4/13 | 0 |
| Lure | 3/11 | 0 |
| LongHall | 6/21 | 0 |
| Hakoniwa（箱庭） | 16/26 | 3/26 = 12%：R(8,5) ~(10,5) U(12,5)，靠诱饵能引过去 |

- 箱庭不改。门槛：每个房间的浪费 ≤ 15%。
- 组合覆盖：11 种机关，能连成连招的两两组合有 42/55（76%），每种机关至少有 3 个搭档。陷阱 Y、笼子 Q 只出现在箱庭里。
- 门槛：每种机关至少 2 个搭档，组合覆盖 ≥ 50%。

## 3. E10 小镇可见度（他每天真走的路，空闲 4 天）

| 东西 | 结果 |
|---|---|
| 滚石 / 水塔 | 3 个镇各 3/4 能碰到他走的路 |
| 巨炮 | 每个镇都有至少 1 门炮口罩在他的路上（你坐的那门 K(63,28) 本来就是给你自己用的） |
| 泥石流 | **原来山镇、雷镇 26 个山坡的泥石流，0 个冲得到他的路 → 真浪费** |

- **修复**：在门 4 旁 (33,16) 加一个山坡（下面垫一座山）。水塔 U(32,17) 淹到它就会引发山洪，不管什么天气，泥沿大路冲到门 4。
- 现在两个镇各有 1 处泥石流冲得到他的路。晴天按水塔就能连出 2 段连锁。地图检查 0 个警告。
- 门槛：每个镇的泥石流至少 1 处能冲到他的路；滚石/水塔至少一半碰得到他；至少 1 门炮罩住他的路。反向测试：去掉这个山坡就报红。
