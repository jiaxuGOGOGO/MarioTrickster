# S229：小镇里心掉光 = 这一天立刻结束（结算 → 重开）

用户（S229）："抛开我的测试和好不好玩，所有想法和调研反馈优化都做完后我再进行一两轮测试……不能把人困死，但是确实要被天灾击杀直接重启，相当于游戏胜利结算重开了。"

## 1. 规则（以前 → 现在）

| | 以前（S220） | 现在（S229） |
|---|---|---|
| 马里奥心掉光 | 晕倒 3 秒、剩 1 颗站起来，一天照常 | **这一天立刻结束 → 你赢**（不管是你的机关还是天灾打死的） |
| 你心掉光 | 同上 | **这一天立刻结束 → 马里奥赢** |
| 同一下两人都掉光 | —— | **平局**（同归于尽） |
| 结束后 | —— | 结算画面写清楚：几点、谁倒下、被什么打死的（"雷区的闪电劈中（天灾）" / "你推的滚石碾到"…）、那之前守住 / 被偷几户。倒下的人**躺在原地**。按 R 马上新的一天，或者 **6 秒后自动开始** |
| 房间里 | 马里奥血量打光 = 你赢，你的命用完 = 他赢 | 不变（本来就是这个规则，现在小镇和房间一致了） |

开关：调参 `overworldDeathEndsDay`（默认开；关掉 = 回到老规则）、`overworldDeathRestartSeconds`（默认 6 秒，0 = 只能按 R）。数值版本 25 → 26。

## 2. "能被打死"但"不会被困死"——怎么保证

| 风险 | 保障 | 证据（sim S229 门槛） |
|---|---|---|
| 来不及反应就死（冤死） | 每一下之前地上先闪 1.2 秒（S220）；挨一下后晕 2 秒 + 站起来再无敌 1.5 秒（S221） | 一直站在雷云里不动（最坏情况、云散了就再叫一朵）：20/20 次被劈死——规则真的会死；但最快也要 13.8 秒（理论下限 7 秒），每一下前都先闪 ≥1.2 秒，两下之间站着能跑 ≥2.2 秒 |
| 不玩也白赢（天灾替你把他劈死） | 他被劈过一次就会躲闪电预警（S220）、在云外等（S221） | 4 个样板镇 × 挂机 15 天：他被天灾打死 0/60（95% 上限 6%）；你 0 次 |
| 会玩的人也白输 | 同上 | 会躲的机器人 60 天：你被打死 0 次 |
| 死了卡在结算 | 6 秒自动重开 + R | 接线检查；结束后时间不再走 |
| 改坏了没发现 | 反向测试 | 把"帧末结算"删掉 → S229 门槛报红 |

H4（AI 不作弊）：马里奥的脑子（`OverworldMind`）不读你的心数，sim 和 EditMode 都查。

## 3. 依据

| 来源 | 规则 | 落地 |
|---|---|---|
| [Quick restarts keep the player involved（Game Design Snacks：Super Meat Boy / Nuclear Throne / Super Hexagon）](https://game-design-snacks.fandom.com/wiki/Quick_restarts_keep_the_player_involved.) | 输了要"马上能再来"，回菜单再进会让人放弃 | R 立刻重开 + 6 秒自动重开，不回菜单 |
| [Smash Bros 自爆规则（SmashWiki）](https://www.ssbwiki.com/Self-destruct) | 被场地机关打死 = 算"自己死"；击杀归最后打中你的人 | 结算写清楚死因 + 是不是你放的；天灾打死他也算你赢（你把他引进雷区本身就是坑法） |
| [炸弹人 Sudden Death（Bomberman Wiki）](https://bomberman.fandom.com/wiki/Sudden_Death) | 场地越来越危险、同时倒下 = 平局 | 同一下两人都没心 = 平局 |
| [Spelunky 设计分析（Game Developer）](https://www.gamedeveloper.com/design/a-spelunky-game-design-analysis-pt-2) | 一击死可以公平，前提是危险看得见；看不见的陷阱才是不公平 | 每一下都先预警（sim 逐下检查） |

## 4. 顺手补的

- **你的反应时间**（S222 审计第 6 条"机器人手抖要真人数据才能校准"）：危险预警出现在你脚下 → 你第一次按方向键，记一次。每天结束写一行 `PlaytestLogs/town_days.csv`（怎么结束的、死因、守住几户、你的反应次数和中位数…20 列）。你测试完我就能拿它校准机器人"愣 0.15–0.6 秒"。不弹任何东西。
- `Step1ExitReport.cs` 缺 Unity 的 `.meta` 文件（S227 漏了）→ 补上（不补 Unity 也会自动生成，补上更稳）。
- 老测试（S220/S221 的"掉光晕倒剩 1 颗""不连控"）改成"关掉开关时"测，规则本身没删。

## 5. 刻意没做

- 不改伤害、预警时长、保护期（只改"掉光以后"）。
- 不加"复活币 / 续命"：用户要的是"结算重开"。
- 房间里不改（本来就是打光就结束）。
