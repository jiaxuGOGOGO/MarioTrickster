# S234 台词你自己说了算：台词编辑器 + "我的台词"文件（升级永远不覆盖）+ 12 轮自我审计

> 一句话：游戏里**所有住户、镇上闲话、马里奥一天结束和中招时说的话**，现在都能在 Unity（Ctrl+Alt+L）或网页里直接改、新加、关掉。你改的东西放在你自己的文件里，**AI 以后升级不会覆盖**，上传 GitHub 时也一起带上。数值版本仍 26，不改玩法。

## 0. 你怎么用（三种方式，任选一种，改的是同一份）

| 方式 | 怎么打开 | 适合 |
|---|---|---|
| **Unity 台词编辑器** | 菜单 MarioTrickster → 台词编辑器（**Ctrl+Alt+L**）；或小镇工坊"🏠 住户与故事"里的"✎ 台词编辑器…" | 平时就用这个。Play 时也能改，下一句就用新的 |
| **网页设计台** | 大地图页 → "✎ 台词本" | 不开 Unity 也能写；点 🔗 连上项目文件夹后，改了就直接写进 Unity |
| 直接改文件 | `Assets/Resources/MyTownStories.json` | 想一次贴很多句时 |

每句能改：**中文 / 英文**（英文可以空着）、**什么时候说**（回到小镇 / 大机关在门口砸中 / 早上 / 一天结束）、**谁说**（6 种住户或任何住户）、**条件**、**真心话 ♥**、**只说一次**、**几天内不重复**、**优先级**。

每句都有三个按钮：
- **这句什么时候会说？** 在当前小镇上彩排 30 天，告诉你"第 12 天 门 1 面包师"，或者为什么没轮到（比如"这张地图上没有画家"）。
- **恢复成内置** / **关掉这句**（内置的）/ **删掉**（你新加的）。

马里奥中招喊的字（"哎哟！""绊倒了！"…和第 3 次的"又是这个？！"）在台词编辑器第二个页签里改。**只能改字**，动作、时长、晕多久都锁着（宪法 H6 / H9）。

## 1. 第一性原理：用户真正要的是什么

"台词可以自定义让我编辑修改"拆到最小有四件事：

1. **找得到**：一句台词在哪、什么时候会出现。→ 搜索 + 筛选（我改过的 / 真心话 / 当场喊…）+ "这句什么时候会说？"
2. **改得动**：不碰 JSON、不记条件名。→ 两个编辑器，下拉框选"什么时候 / 谁说"，条件旁边写着能用哪些。
3. **改了不丢**：AI 升级、换电脑、换账号都不丢。→ 你的改动单独存一个文件 `MyTownStories.json`，补丁永远不碰它；bat 上传 GitHub 时把它当**你自己的提交**一起传；每次保存在 `MarioTricksterBackups/MyTownStories/` 留一份备份（最近 20 份）。
4. **改了不坏**：写错不会让游戏坏掉，也不会悄悄失效。→ 写坏的句子跳过并告诉你原因；条件名 / 占位符写错、真心话没设"只说一次"、关掉太多导致"有人会沉默"都会提醒。

## 2. 12 轮自我审计（每轮 = 用你的视角走一遍 → 找到的问题 → 改法）

## 4. 永久规则（追加）

21. **用户写的内容归用户**：`Assets/Resources/My*.json` 只由用户（或用户的编辑器）写；AI 的补丁不许包含、不许修改它们（sim 检查）。AI 要改默认台词只改 `TownStory.Default` + `TownStories.json`。
22. **读台词只走一个入口**：游戏 `TownStory.Load`、编辑器 `TownStoryEditorWindow.Effective()`；新加读台词的地方也必须用它（否则看不到用户的改动——第 9 轮的 bug）。
23. 新加 `when` 时机 / 新事实 key：同步改 `TownStory.FactKeys`、网页 `TS_FACT_KEYS`、编辑器的"什么时候说"下拉框。
24. 马里奥头顶的字可以给用户改；**动作 / 时长永远不开放**（H6 / H9）。
