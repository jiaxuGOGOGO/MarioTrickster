# S235 掉出房间回不来：修好了，同类问题一起查过

> 一句话：以前捣蛋者被炮或炸弹轰出房间、被挤出外墙之后，**人就停在房间外面回不来，命也不掉，马里奥照样跑**。现在房间外面多了一圈**看不见的墙**，正常情况下根本出不去。万一还是出去了，你会**回到出生点并掉 1 条命**，马里奥掉出去也会被放回他的路上。小镇里也加了同样的兜底。

## 1. 为什么会掉出去（找到 4 个原因）
| # | 原因 | 结果 |
|---|---|---|
| 1 | 房间底下的"深渊"只认身上有血条的角色，**只有马里奥有，捣蛋者没有**；而且它只管往下掉，从左右或上面出去没人管 | 你掉下去：命不掉、不回出生点、这一局卡在那里 |
| 2 | "身体嵌进墙就推出来"（S209）按最短的方向推。被炮、炸弹、伪装变大挤进**最外圈的墙**时，最短方向可能是**往外推** | 被推到房间外面 |
| 3 | 搭建检查只要求外圈是"实心"的，但单向台面 `-`（能从下面穿上去）、塌桥 `C`、裂缝地板 `x`、箱子 `c` 也都算实心 | 外圈可能留了一个会塌、能穿过去的口子 |
| 4 | 镜头只在房间范围里移动 | 掉出去以后屏幕上看不见你，也没有任何提示 |

## 2. 怎么修的（三道保险）
| 保险 | 做法 | 你会看到 |
|---|---|---|
| A 预防 | 每个房间的外圈墙外面再围一圈看不见的墙（3 格厚、四个角重叠没有缝、炸不掉）；"推出墙"只会往房间里推 | 被炮轰到墙上会撞回来，不会飞出去 |
| B 兜底 | 每帧都检查：你的身体中心越过外圈墙的中线，就算掉出房间 → **回出生点并掉 1 条命**（还在无敌时间里就只回去、不掉命）。命用完 = 这一局马里奥赢，结算写"你掉出房间，命用完了" | 底部提示"你掉出房间了 → 回出生点，-1 条命"，有冲击圈和震屏 |
| B 兜底 | 马里奥掉出房间 → 用卡住救援的那套办法放回他的路上，胜负不变，记一次 stuck_rescues | 提示"马里奥掉出房间了 → 已放回（布局问题，按 F8）" |
| C 提醒 | 关卡工坊和网页设计台里，外圈上放了"会塌、能穿、能炸"的格子 → **黄色提醒** | 画关卡时就能发现口子 |

## 3. 顺手修的衍生问题
| 问题 | 原因 | 修法 |
|---|---|---|
| 你被吊在绳套上时，被抓或掉出去回了出生点，下一帧又被**拽回绳套** | 绳套每帧都把人固定在上方 | 人被传送走了就放开 |
| 铁笼同样的问题 | 笼子每帧都锁住人的水平位置 | 同上 |
| 你钻进大炮正在装填时被抓回出生点，0.6 秒后又被**拽回炮口发射出去** | 装填结束时没检查人还在不在炮里 | 人不在炮口附近就不发射 |
| 贴着外墙放的诱饵会走进墙里或走出房间（马里奥会去追它） | 诱饵只是一个画面、没有碰撞体 | 诱饵限制在房间里面 |
| 小镇：人的身体压进墙、树里或跑到地图外以后，**永远动不了**（落点算歪、从房间带回来的位置不对时会出现） | 每走一步都被挡住 | 每帧检查：压进去了就挪到最近能站的格子（坐炮和飞行时不算） |

## 4. 数值（都在 RushMarioTuning 里，带中文说明）

## 5. 规则保障
- H9（不能卡死）：房间里多了 3 道保险；小镇压进墙一帧内就能救出来。
- H4（AI 不作弊）：房间守卫是"裁判"，马里奥的思考代码里不读它（体检会查）。
- H1（马里奥一定有路可走）：看不见的墙在外圈墙的**外面**，房间里一格都没挡（体检逐格检查过）。

## 7. 刻意没做的（避免矫枉过正）
- 没有把"掉出去"直接判输：出去一次只掉 1 条命，数值可以调成 0。
- 没有改默认房间和样板：它们的外圈本来就只有 W 和 #。
- 没有给捣蛋者加血条系统：命数就是你的血，掉出去就扣命，和被抓走的是同一个计数。
