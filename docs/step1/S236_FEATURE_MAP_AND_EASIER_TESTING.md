# S236 全部功能梳理：功能地图（开始页）+ 防遗忘规则 + 测试更顺手

> 一句话：项目到现在一共有 **56 项功能**，分成 8 个区。全部登记在**一份功能地图**里：Unity 里按 **Ctrl+Alt+H** 打开"开始页"，网页设计台多了一个"功能地图"页，仓库里还有 `docs/FEATURE_MAP.md`，三处内容完全一样。以后任何菜单、按键、网页面板、说明文档**没登记 = 体检报红**，功能删了却留着登记也报红，所以不会再有"做了却找不到"的东西。梳理过程中顺手修了 6 处交互和测试上的别扭。

## 4. 修掉的交互 / 测试别扭
| # | 别扭在哪 | 为什么 | 修法 |
|---|---|---|---|
| 1 | 结算问卷**按数字 1–5 有的机器没反应**，卡在问卷上 | 问卷数字只读旧输入系统（S197 修过别的键，漏了数字） | 两套输入都读，主键盘和小键盘都行 |
| 2 | 想反复试一个机关，炸弹 3 颗、诱饵 1 个用完就得重开 | 没有测试用的"无限" | **F9 = 技能无限、没冷却**（炸弹 / 缩小 / 诱饵 / 挑衅 / 机关），左上角写"F9 测试"；开过 F9 的局只记一行 mode=f9，**不弹问卷、不算进第 1 步出口** |
| 3 | 被自己的炸弹炸光命，结算写**"马里奥带着宝物逃走了"** | 结算只认"被抓"和"掉出房间"两种输法 | 写"你被自己的机关炸光了命" |
| 4 | 马里奥**停时间**时，你冻住的身体会慢慢沉进地板（2 秒约 3 格），解冻后可能掉出房间 | 冻住时硬直代码仍然每帧写重力速度 | 身体冻住时不写速度（你和马里奥两边都改；弹跳台蓄力同理） |
| 5 | 一局在你被冻住时结束 → 结算时你还冻着，直到下一局 | 时间静止只在"进行中"才计时 | 一局结束马上解冻 |
| 6 | 帮助里大炮说明写了两遍、两种说法 | 历次加功能各写了一段 | 留一段；帮助最后加一行"测试用：F9 / F5 / Ctrl+Alt+H" |

## 5. 防遗忘规则（体检 S236 自动查，以后 AI 必须遵守）
1. 每个 `MarioTrickster/` 菜单、每个游戏按键、网页每个页签和面板标题、`docs/step1` 每篇说明，都必须被功能地图某一项登记。
2. 每一项写一个"锚点"（文件 + 一句代码）：代码删了，体检就提醒"这一项找不到了"，所以登记里不会留死链。
3. `docs/FEATURE_MAP.md` 和网页功能地图都由 `FeatureMap.cs` 生成，体检逐项对照（不许手改）。
4. 加新功能时先问：能不能并进已有一项？是"常用"还是"进阶"？并在 `since` 写 Session 号，开始页"🆕 最近新增"会自动显示它。
5. 开始页在功能地图有变化时（升级后）自动弹一次，之后不打扰。
