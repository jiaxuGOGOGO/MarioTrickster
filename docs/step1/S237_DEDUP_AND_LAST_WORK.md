# S237 去冗余 + 开始页「上次做到哪」

> 用户原话："自我检查是否存在重复冗余的情况，因为足够多的重复也会让我难以使用、测试反复、增加放弃的成本……可以调整数值的是否可以整合还是删除……在开始页加上次做到哪……清理旧工具：你可以做完整合，通俗介绍哪些你认为可以删并且为什么、哪些可以整合，我确认后再继续。"

## 0. 第一性原理：什么算"冗余"

用户的时间只花在三件事上：**想点子 → 摆出来 → 玩一下看对不对**。任何东西如果不服务这三步，就是负担：

| 冗余的样子 | 为什么伤人 | 判断标准 |
|---|---|---|
| 同一件事有两个入口、名字还不一样 | 不知道该用哪个，两个都试一遍 | 一件事只留一个主入口，其他入口只是"快捷方式"指向它 |
| 改了没反应 | 以为没改对，反复改反复重启 | 改了就必须看得到效果 |
| 一长串找不到 | 找 1 个数翻 250 行 | 常用的放最上面，其他按"想调什么"分组 |
| 留着的旧东西 | 菜单里一半看不懂，怕点错 | 新做法全覆盖、没人引用 → 可以删 |
