## 3. 你要做的

1. 双击 `install_and_upload.bat`，选 Y。
2. Unity 里 Ctrl+Alt+T → 🧪 跑 EditMode 测试，应全部通过。
3. 选中 `Assets/Resources/Step1/RushMarioTuning`：看「马里奥性格」下拉，和「你的技能」组里新加的扫描 / 能量 / 附身。按 ▶ 玩一局，按 F5 应能重开。

**风险**：如果你本地改过 `GameplayLoopConfig.asset`，安装可能停下（因为这次要删它）。bat 会提示，截图发我即可。
