# S239 按"好玩"整合：删掉和现有玩法重复的旧系统

> 用户："不考虑任何宪法 只考虑游戏好玩的初衷对系统进行整合 玩的过程中已经重复的可以考虑删除其他考虑整合 基于此看是否删除"

## 1. 结论

删了 21 个旧系统（约 7000 行）。它们在房间和小镇里**本来就不运行**：要么建场景时根本不装，要么装了又马上拆掉。而它们想做的事，现在的玩法里都已经有了。所以**你玩到的东西完全不变**，只是代码少了一大块，以后不会再有人（包括 AI）把它们"打开"，变成和现有玩法打架的第二套规则。

## 2. 每个旧系统 → 现在由谁负责

| 删掉的旧系统 | 它想做什么 | 现在玩的时候已经由谁做 |
| --- | --- | --- |
| 热度条（TricksterHeatMeter / HeatBreachHint / HeatSuspicionBridge） | 你捣蛋越多，马里奥越警觉 | **起疑条**（SuspicionMeter）+ 马里奥被坑过的地方会放慢（学习层）+ 警报事件 |
| 警报危机导演（AlarmCrisisDirector） | 热度满了放一道扫描波 | 回合里的**警报事件**、马里奥的 Q 扫描、时间静止 |
| 连锁追踪（PropComboTracker） | 连着用不同机关加分 | **连击计数** + 连招计分（同类机关只算一半、换种类 +5）+ 连锁编排 F |
| 重复干扰叠加（RepeatInterferenceStack） | 老用同一招效果变差 | 同类只算一半、晕眩越来越短、马里奥说"第 N 次了"、马里奥记住被坑过的位置 |
| 路线预算（RouteBudgetService） | 不许把马里奥的路全堵死 | **死局检查** + 策略模拟 + 卡住救援 + 马里奥踢门（这个服务以前就没接上，机关一直直接放行） |
| 干扰补偿（InterferenceCompensationPolicy） | 你出手后给马里奥补点线索 | 被坑 +25 起疑、看见你出手 +45 起疑、马里奥的学习层 |
| 反揭露奖励（CounterRevealReward） | 被抓到后的奖惩 | 被抓 = 掉一条命 + 马里奥庆祝 + 起疑条清零 |
| 第 0 步的锚点起疑层（MarioSuspicionTracker、AnchorSuspicionData、SilentMarkSensor、MarioCounterplayProbe、ResidueVisualHint、SuspicionHUD、LootEscapeHUD） | 旧马里奥怎么"怀疑"某个道具 | 第 1 步的马里奥：**MarioEyes**（看）+ **RushMarioMind**（想）+ 起疑条 + 干净界面 Step1Screen |
| 旧界面（GlobalGameUICanvas、GameUI、InteractionLogSink + 预制体 + 生成器、UI 层设置） | 旧 HUD | **Step1Screen** + 提示条 + 失败原因提示（Step1FailFeedback） |

顺带清掉的东西：
- 3 个没人用的调试开关（无敌、无限能量、秒融入）。第 1 步的"无限技能"一直用 F9。
- 机器人性格里的"连击偏好"。
- 逃生门的"热度高时晚点开"。
- 宝物的"拿到加热度"。
- 状态队列机关的"热度罚分"。
- 事件里的"热度换档"和"揭露"两种消息（已经没有人发）。

**原样保留**：
- 视线检测：从旧起疑追踪器里一字不改地搬进 `SightLine`。马里奥的视野、视野锥、捣蛋者、炮弹都用它。
- 闪白和震屏（VisualFeedbackBridge）、扫描、附身。
- 回合里的警报事件。

## 3. 没有删、但值得你拍板的 2 个点子

这两个旧系统里有现在玩法**没有**的想法。这次只删代码、不做新东西，等你决定要不要做成新玩法：

1. **残留痕迹**：你在某个道具上藏过，那里会留下一点痕迹，细心的马里奥能发现。它能让"换地方藏"有意义。
2. **越坑越警觉**：现在的警报是随机来的。可以改成看你捣蛋多少次、连击多少来触发，或者让马里奥每被坑一次，起疑条就降得慢一点。注意：变化一定要让你看得见，否则会伤"被抓得服气"。

## 4. 你要做的

1. 双击 `install_and_upload.bat`，选 Y。
2. Unity 里 Ctrl+Alt+T → 🧪 跑 EditMode 测试，应全部通过。
3. 按 ▶ 玩一局房间、一局小镇。第一次进入时场景会自动重建一次（BuilderVersion 21 → 22，正常现象），玩起来应和以前一样。

PlayMode 测试从 34 条变成 33 条，删的是测旧界面的那条。

## 5. 永久规则

- 这些旧系统已经删了。**不要再拿宪法第 4 步"加回扩展系统"把旧代码找回来。**想要上面 §3 的点子，就在现在的系统上做新的。
- 视线检测只用 `SightLine.CanWitness` / `SightLine.IsOneWayPlatform`。
