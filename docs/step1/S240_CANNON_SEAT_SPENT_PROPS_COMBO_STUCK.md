# S240：坐进大炮自己飞 · 用过的机关变灰 · 连击看得懂 · 卡住检测帮搭图

来源：S239 试玩反馈（3 张截图）。

## 1. 大炮：坐进去，自己按空格发射

| | 以前 | 现在 |
|---|---|---|
| 怎么进 | 碰到就自动吸进去（只有炮弹打完才行） | **没伪装站在炮口按 ↓**（有没有炮弹都能坐） |
| 瞄准 | 0.6 秒内按几下 | 坐着慢慢调：**←→ 调方向，按住 ↑↓ 连续调角度**，金色炮管 + **虚线轨迹**（撞墙就停在墙上） |
| 发射 | 0.6 秒后自动 | **空格（或 L）**；坐满 8 秒自动发射 |
| 多远 | 速度 18.5：40° 约 8 格远、1.6 格高 | 速度 26：40° 约 15 格远、3.3 格高；70° 约 7 格高 |
| 再进 | 冷却 30 秒 | **落地 1.5 秒后就能再进** = 可以反复进 |
| 坐着时 | 能走出去 | 身体锁在炮里，B/G/T/Z/P/跳都不生效；被抓 / 回合重置会自动放开 |

- 底栏：站在能进的炮口时出现「↓ 坐进大炮」；坐着时底栏换成「← → 调方向 ↑ ↓ 调角度 空格 / L 发射 · N 秒后自动发射」。
- 马里奥：不变（打完炮弹后才钻，速度 18.5，冷却 30 秒）。
- 调参（「机关」组 → S240）：`tricksterCannonSpeed`、`tricksterCannonCooldown`、`tricksterCannonMaxSitSeconds`。

## 2. 用过的机关：变灰 · 不选 · 不连线 · 不编号

规则（`ControllablePropBase.SpentThisRound`）：
- **本回合用光了**（裂缝已碎、铁笼已落、次数用完）→ 变灰，选目标、红线、F 连锁编号全跳过。回合重置后自动恢复颜色。
- **冷却中**（等一会儿还能用）→ 不变灰；选目标时排在能用的后面，只剩它时才选它（按 L 会提示冷却）。
- **大炮**炮弹打完不变灰：它还能坐进去飞。
- 已经绑定的机关刚被用光 → 马上换到最近还能用的；一个都没有就解绑（红线不再指着用过的）。
- 开关：`greySpentProps`。

## 3. 连击看得懂（连击 ≠ 连锁）

**连击**看时间：任意两下「坑到马里奥」间隔不到 4 秒（`comboWindowSeconds`）就算 x2，不管是哪两个机关、是不是你按的。
例：大炮打中他（第 1 下）→ 3 秒内他踩到香蕉皮（第 2 下）= x2 连击。

**连锁**看编号：你按 F 给机关编 ①②③，触发任意一环后，其余几环在他走到时自动触发。连锁里的每一环坑到他，也会算进连击。

现在怎么显示：
- 第 1 下：马里奥头顶出现**黄色倒计时条** + 一句「坑到了：炮弹　条走完前再坑一下 = 连击」。
- 第 2 下起：弹窗写「x2 连击！」，下面一行写**是哪几下**：`炮弹 → 香蕉皮`（最多显示最后 4 下）。
- 原因名：炮弹 / 爆炸 / 火 / 绊线 / 香蕉皮 / 弹簧 / 铁笼 / 绳套 / 掉下一层 / 掉坑 / 被墙挡住。

连锁编号：
- 只在**你附近**（`chainAutoRange` 格内）或**连锁进行中**才画；打完的环不画。
- 挨得太近的编号自动错开；**下一环放大**；相邻两环之间画一串点（谁接谁）。
- 右上角一行清单：`①火 → ②香蕉皮 → ③大炮`（打完的变灰，下一环加粗）。

## 4. 卡住：运行时 + 搭图时都帮你找

运行时（`Step1StuckRescue`）：
- 以前：被晕、东张西望、躲闪时计时**清零** → 坑底有火反复烧他，永远凑不满 6 秒，就一直卡着（截图 1）。
- 现在：这些时候计时**暂停不清零**；另加总兜底 `stuckHardCapSeconds`（默认 15 秒到目标没进展，不管在干嘛都救）。
- 救援位置以前按静态地图选，可能放回已经塌掉的桥上 → 又掉下去。现在先用物理查一下脚下真有地面再放。
- 每次救援自动记一行到 `PlaytestLogs/step1_stuck.txt`（哪张图、哪一格、为什么），并自动截一张图（30 秒内最多一张）记进 F8 反馈。开关：`stuckAutoReport`。

搭图时（工坊 → 检查轨迹）：
- **黄格 = 临界跳**：只能靠往上跳满 2 格才出得去的起跳格（2 格就是马里奥跳高的极限，被弹一下、落点偏一点就上不去）。塌桥、裂缝地板**塌后**也会再查一遍。建议：在黄格旁边加一级台阶，变成两次 1 格跳。
- **红叉 + 数字 = 试玩时他在这里卡过几次**（读 `step1_stuck.txt`，只显示这张图的）。
- 不用先跑自动检查，打开「检查轨迹」就能看到这两样。

默认房间：塌桥坑两边各加了一级台阶（以前出坑要跳满 2 格，坑里还有火）。检查后：默认房间 3 种布局都是 0 个黄格；箱庭样板还有 6 个黄格（楼梯每级都是 2 格），留给你决定要不要改。

## 故意没做

- 没改马里奥 AI 的跳法（跳高极限是物理手感，改了会影响所有房间）。
- 没把箱庭样板的楼梯改掉（是你设计的；检查会标黄告诉你哪几级）。
- 连击的计分规则没改（只改了显示）。
