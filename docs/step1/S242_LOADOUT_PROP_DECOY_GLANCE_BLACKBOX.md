# S242：伪装装备栏 · 道具诱饵 · 一目了然 · 试玩黑匣子

> 用户原话（摘）：如何打包上传的反馈包括任何我在 unity 测试可能出现的问题 比如卡住……并且保证大小可控 最精确的反馈给出最精确的修复；
> 捣蛋者可以选择三个（或者更多可自定义）游戏场景内的道具或者机关本身，同时丢出的诱饵也是选择的这三个中的任何一个 可以自由切换；
> 按 M 或者 V 出现的一堆文字……极大增加认知负担……生成清晰易懂的美术素材让游戏干爽整洁一目了然要做什么 要避开什么。

## 1. 试玩黑匣子（反馈包升级）

| 以前 | 现在 |
|---|---|
| F8 = 全尺寸 PNG（1–4MB 一张） | 缩小 JPG（最宽 960，质量 72，≈100KB），在提示框画出来之前截 |
| 只有一行"当时情况" | 每条另存 `blackbox_NNN.md`：最近 25 秒（4 次/秒）马里奥和你的位置 / 速度 / 状态 / 按键 / timeScale / fps + 出事前 150 条面包屑（提示文字、机关、爆炸、救援、错误）+ 房间字符画上标 M / T |
| 卡住才自动截图 | 自动检测 6 种：马里奥卡住（4 秒不挪窝）、按住方向键你不动、画面顿卡（>0.3 秒一帧）、位置 NaN / 出房间、timeScale=0 超过 6 秒且没暂停、同一个键 2 秒狂按 6 次（按了没反应） |
| 无上限 | 同一类 30 秒最多一次，一次试玩最多 25 条 |
| 要打字补充 | F8 后 3 秒内按 1–4 打标签：卡住 / 别扭 / 看不懂 / bug |
| 打包全部文件、不压缩 | 首页自动总结（每类几次 + 最该先看的 3 条）+ 环境（Unity / 系统 / 显卡 / 调参版本）+ Unity 日志里的错误行（≤80KB）；按 8MB 预算挑文件（说明 / 事件表必带，黑匣子其次，截图新的优先，超了丢最旧的并写明丢了哪些）；文字 Deflate 压缩 |

sim 实测：80 条记录 → 7.9MB；一份黑匣子 ≈8KB；一直卡住 10 分钟只记 20 条。

参考：Sentry breadcrumbs（最近 100 条操作）、PlayReport（一键报告 = 回放 + 日志 + 系统信息，异常自动报）、BetaHub（滚动日志、限大小）、Bugnet（截图先缩小、在报告界面画出来之前截）、Unity 论坛（EncodeToJPG 代替 PNG）、vav-labs（bug 报告要证据）。

## 2. 伪装装备栏 + 道具诱饵

- 屏幕底部一排小格 = 你能变的形态。默认 = **这个房间里最多的 3 种东西**（藏木于林；`disguiseLoadoutSize` 1–5）。
- 外观照抄房间里真的那个：图 + 颜色 + 大小 + 图标；碰撞体夹在 0.6–1.2 格（不钻墙缝、不卡门洞）。
- 数字键 1–N 换形态，**伪装中也能换**；代价：换的一瞬间（0.5 秒）他正看着你 = 算你动了（起疑）。
- 站在箱子 / 草丛 / 油桶 / 灯旁按 **E** = 把它取样进当前格（已有的两格交换，不重复）。
- **G = 丢一个当前形态的假道具**（Witch It 的做法：诱饵 = 你正在模仿的道具）：伪装中也能丢，抛物线落在 2.5 格外，每 1.6 秒扭一下；他看见扭动 = 可疑的东西 → 过来查看 → 走近 2.5 格识破。你老实装道具而诱饵在扭 → 他先看诱饵。Shift+G = 以前那种"假你"（仍要现形）。每局诱饵 1 → 2 个。
- 马里奥仍只用眼睛（同一视锥 + 遮挡 + 光照），不读装备栏（H4，sim 检查）。

参考：Witch It Decoy、Prop Hunt（CoD / PUBG：只能变成这张图里有的东西）。

## 3. 一目了然（代替 M / V 的一堆字）

- **马里奥头顶一个图标气泡**：宝箱 = 去拿宝、门 = 要逃了、? = 起疑、! = 追你、眼 = 找你、星 = 晕了。
- **马里奥接下来要走的路**：一串小点（平时淡淡的；按 M 变亮）。用的是他自己寻路的同一个 LevelPathPlanner。
- **按 M = 作战图**：路线上他最先经过的 3 个机关标红色靶心"埋伏点" + 2 个字的动词 + 几秒后到；只给离你最近的一个东西出说明卡（图标 + 名字 + 一句话）；左下角图例改成三色图标格子（每格 = 图标 + 名字 + 2–4 个字的动词）。
- **V**：只写"名字 · 动词"一行（以前中英两行）。
- 颜色只有三种：红 = 坑他、蓝 = 躲 / 钻、黄 = 目标。
- 新增 8 个 16×16 徽章图标（tools_s242/gen_icons.py 代码生成，过描边 / 填充率检查；没有用 AI 生图：像素对不齐、切图不稳定）。

参考：Into the Breach（把敌人意图画在棋盘上；"为了清晰牺牲酷点子"）、Riot《Clarity in League》、Untitled Goose Game（图标清单 + 意图气泡）、Mark of the Ninja（感知范围画在世界里）、反例：侦探视觉常开 = 拐杖（所以作战图是按 M 看一眼）。
