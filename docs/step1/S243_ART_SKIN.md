## 参考（做法，不搬素材）
- 主层（角色 / 机关 / 地形）实心深描边、背景低对比无描边，玩家一眼分清"能碰的"和"装饰"：https://www.sandromaglione.com/articles/pixel-art-platformer-level-design-full-guide
- 16×16 角色：先剪影、大头（头约占 45%）、眼睛最重要、颜色少：https://spritegen.io/guides/how-to-draw-a-pixel-art-character/
- 障碍物看不清的通病 → 拉开明度、背景去饱和、前景加描边：https://www.reddit.com/r/gamedev/comments/w5w6xd/
- 16×16 一眼可读的图标做法（S241 起）：https://kenney.nl/assets/1-bit-pack

## 怎么做的（可复现）
1. GPT Image 2 生成 7 张洋红底图（角色 ×2、机关 ×2、徽章、地形、背景），提示词要求原创、16-bit、粗深描边、少颜色。
2. `AI_CONTINUE_PACK/scripts/tools/art_s243/slice.py`：去洋红 → 按行列切格 → 预乘透明度缩到 16×16 → 吸到项目调色板（OverworldArt.Palette + 4 个新色：皮肤亮 / 暗、深蓝、暗灰）→ 外轮廓深色不足 80% 自动补描边。
3. `gen_art.py` 写出 `Assets/Scripts/Gameplay/Step1/Step1Art.cs`（纯数据，sim 里编译）。
4. 每张图过 `OverworldArt.Audit`（≤16 色、深描边 ≥75%、剪影 15–85%）。

## 运行时（Step1ArtSkin）
- 房间生成器挂到 GameManager；`[DefaultExecutionOrder(-1000)]` → 在所有 Awake 之前换图并把颜色改白。机关 / 角色在 Awake 里记"原色"，记下的就是白色 → 预警闪烁、用光变灰、受伤红白闪都照常，不会把像素图染成色块。
- 只换 `Visual` 的 sprite / 颜色 / 视觉缩放；**碰撞体、判定框、视碰对齐全都不变（H3）**。角色图 16px = 1 格、pivot 居中，和原来的方块占同一块地方。
- 扁机关（香蕉皮、黏胶、绊线…）：图取 0.6–1 格大小，底边对齐原色块底边（`FitScale` / `FitLift`）。
- 地形用 Tiled 平铺；炸弹炸开后的碎块也平铺（Destructible 改了一行）。
- 大炮炮管 / 炮弹以前借本体的白方块，换图后改用 `Step1Sprites.Square`。
- 伪装中不改捣蛋者的图（DisguiseSystem 在画那个东西）；变身 / 现形那 0.25 秒显示变身烟。
- 装备栏快捷格总画一张图（换了像素图的东西身上不叠小图标，但格子里要画）。
- 已经换过主题美术的（不是 4×4 白方块）一律不动。
- 自己的图：同名 PNG 放 `Assets/Resources/Step1Art/<Key>.png`（Hero0–4、Imp0–4、FireTrap…、GroundTop/GroundFill/Wall/Platform）。

## 调参（DataVersion 32，组：镜头 · 屏幕 · 好不好读）
`artCharacters` / `artProps` / `artTiles` / `artBackground`，默认全开；关掉 = 回到 S242 的样子。BuilderVersion 24 → ▶ 试玩会自动重建一次场景。

## 只能在 Unity 里确认的
- 角色帧的脚底是否贴地（视碰对齐是按原方块算的，图里人物下面若有 1 像素空白会显得悬空 1/16 格）。
- 地形平铺接缝、背景盖满整个房间、夜晚遮罩（S241）叠在背景上的观感。
- 机关预警闪烁在像素图上是否够显眼（原来是整块色块变色，现在是图整体染色）。
- 伪装成机关后，你的外观 = 房间里那个机关的像素图（S242 装备栏照抄房间里的 sprite）。
