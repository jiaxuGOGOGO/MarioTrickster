## 2. 动作画面 + 节奏
- 跑得快时脚下扬尘（每 0.22 秒一团）；从高处落地扬尘，落得越猛尘越大。
- 小恶魔落地压扁 0.12 秒；变身 / 现形冒一团烟。
- 开局最后 3 秒大字 3 · 2 · 1，出发那一下"开始！"（数字砸下来再缩回）。
- 他拿到宝 → 横幅"他拿到宝了！拦住他回出口"；剩 10 秒 → "最后 10 秒！"。1.6 秒淡出，不挡操作。
- 开关：调参 `artJuice` / `startCountdown` / `roundBanners` / `screenShake`（S244 组）。

## 3. 房间暂停菜单（Esc）
继续 / 重开这一局 / 怎么玩 / 设置 /（从小镇来时）回小镇 / 退出。↑↓ 选、Enter 确认、数字键直选。
设置：游戏速度（×0.5–×1 五档）、震屏、声音圈、像素美术、开局说明、开局倒计时——改的就是唯一的调参文件。

## 4. 小镇暂停 + 存档
- Esc：继续 / 现在存档 / 怎么玩 / 重新开始这一天 / 退出（退出前自动存）。暂停时时间停住。
- 自动存：进小镇 1 秒后（= 从房间回来）存一次，之后每 20 秒一次。天亮结算后删掉存档。
- 下次 Play 第一次进小镇：问"继续上次那一天？"（Enter 继续 / N 新的一天）。快速测试模式不问。
- 存的内容：第几天、几点、下一站、每扇门结果、心、能量、两人位置、今天改过的地形。
- 坏档 / 旧版本 / 数字离谱 → 当没存档，从新的一天开始（不报错、不卡死）。房间打到一半不存（一局 1–2 分钟，从门口重来）。
