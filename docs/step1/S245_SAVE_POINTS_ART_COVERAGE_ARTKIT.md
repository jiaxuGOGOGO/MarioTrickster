## 1. 存档进度点
| 时机 | 存到哪 | 说明 |
|---|---|---|
| 每 20 秒 | 自动位 | S244 就有 |
| 进门前 | 自动位 | 关掉游戏不会回到 20 秒前（可能已经过了那扇门） |
| 房间打完回到小镇 | 自动位 | `TownSaveStore.RoomJustDone` |
| 天亮结算 | 自动位 | 存"第 N+1 天早上"（S244 是删档 → 下次又是第 1 天） |

- 下次进小镇：继续列表按时间排，最新的默认选中；每行写"自动 · 进门前 · 第 2 天 14:30 · 守住 1 扇 · 10-09 15:20"。

## 3. 素材包：换画风 + 素材自带互动
菜单 **MarioTrickster → 美术 Art → 🎨 素材包 换图 + 互动**（第一次打开自动建 `Assets/Resources/ArtKit/MyArtKit.asset`；这是你的内容，补丁永远不覆盖）。

- **换图**：左边按组列出所有名字（素材槽 / 房间元素 / 角色帧 / 地形 / 小镇 / 装饰 / 特效 / 徽章），右边把 Sprite 拖进"换上的图"——房间、小镇、图例全换，不改代码不改关卡。可加动画帧。
- **批量换一整套画风**：📤 导出模板 PNG（`Assets/Art/Templates`，每张图按名字）→ 画师照名字画 → 放进 Assets 下一个文件夹 → 📂 批量导入（`PoisonPool.png` / `PoisonPool_v2.png` 都认），自动设成像素图（Point、不压缩、可读）。
- **互动**：任何名字都可以勾"有互动"：掉血 / 回血（半格、一格、一格半…三格）、每隔几秒、减速、每次晕几秒、马里奥会中 / 你会中。例：给内置毒池 PoisonPool 设"每 1 秒掉一格"，房间里所有毒池都会扣血（加一个触发区子物体，原来的碰撞体不动）。
- **4 个素材槽 z Z a r**：关卡里直接画这 4 个字符（和毒池一样最多 3 格宽）。默认：z 毒池（每 1.2 秒掉半格 + 减速）、Z 荆棘（每 1.6 秒掉一格 + 晕 0.25 秒）、a 回血泉（每 2 秒回半格）、r 蛛网（减速到 0.45）。长相和互动都在素材包里改。
- 半格怎么算：马里奥的血和你的命都是整颗 → 两次半格 = 真扣一颗，攒着半格时头上显示半颗心。
- 你在毒池 / 荆棘里掉光命 → 结算写"你在毒池 / 荆棘里掉光了命"（不是"被自己炸光"）。
- 安全线（H9）：间隔 ≥0.3 秒、晕 ≤1.5 秒、减速不低于 0.2 倍、一次最多 3 颗心。马里奥的心智不读素材包（H4）。
- 🎯 跳到选中物体：在场景里选一个元素，直接定位到它的名字。
