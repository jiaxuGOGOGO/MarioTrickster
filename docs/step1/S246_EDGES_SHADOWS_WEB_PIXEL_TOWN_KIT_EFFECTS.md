# S246 地面过渡边 · 影子 · 网页像素小镇 · 素材包更多效果（不用写代码）

用户原话："还没做的：网页关卡设计台里的小镇还是色块，Unity 里已经是像素图。小镇的路和草之间没有过渡边，物体也没有影子（AI 评审提的）。新机关如果要掉血、回血、减速、晕以外的新效果，还得写代码 —— 继续更新并加入到完整推送包一起打包交付"

## 1. 地面过渡边（Unity 小镇 + 网页同一套）
- 规则 `WorldArt.GroundPixelKey`：层级 草 > 泥 > 路 > 水。层级高的地面在交界处往邻居里长出 1–4 像素的不规则毛边（越靠边越密）。毛边位置由格子和像素坐标算出来，同一张地图每次都一样。
- 圆角：两条相邻边都挨着同一种更高层级的地面时，外角切成圆弧。池塘四角是圆的，草里的泥地、路口不再是直角。
- 水：岸边一圈浅色水边。
- 网页 `app.js owGroundPixelKey` 和 C# 是同一个算法：sim 拿 2400 个样例逐个比对，结果必须完全一样。
- 只有和邻居不同的格子才逐像素画，大地图也不卡。

## 2. 影子
- 树、山、房子墙脚那一排、栅栏、家、帐篷、木箱、滚石、水塔、钟楼、巨炮、路灯脚下各有一块半透明椭圆影子（略往右偏，像下午的太阳）；马里奥和你脚下也有，跟着人走。
- 影子排在地面上、所有物体下面（sortingOrder −1900）。没有碰撞体，纯画面（H3）。
- 关掉 artTown = 色块模式，没有影子。

## 3. 网页关卡设计台：小镇像素画面
- 大地图页工具栏新开关 **🎨 像素画面**（默认开）。小镇用和 Unity 一样的图块（`WorldArt.Town`，build.py 自动导出）、过渡边和影子画；门上标门号；道具 / 机关仍用小镇图标。
- 缩放小于 8 或关掉开关 = 回到看得清格子的色块。错误红框、路线、夜晚、关系线、雷区照常叠在上面。

## 4. 素材包：更多效果不用写代码
在 🎨 素材包里，互动多了 5 项（每一跳生效）：
| 效果 | 设置 | 例子 |
|---|---|---|
| 往上弹 | 格/秒（15 ≈ 弹高 2.8 格，和弹簧板同一套重力） | 蹦床、喷泉 |
| 一直推 | 格/秒，正 = 右、负 = 左 | 大风、传送带、冰面 |
| 从中间弹开 | 格/秒 | 地雷、爆炸桶 |
| 打回原形 | 勾 | 探照灯（你伪装时进去会现形） |
| 只生效一次 | 勾 | 地雷、一次性补给（生效后消失） |

还加了 **一键套用预设**（10 个）：毒池 / 荆棘 / 回血泉 / 蛛网 / 蹦床 / 大风 / 传送带 / 地雷 / 探照灯 / 冰面。先套一个最像的，再微调数字。
安全线：弹 ≤24、推 ≤8、弹开 ≤16 格/秒（`ArtKitRules.Clamp`）；推用的是和传送带同一个接口（`SetPlatformVelocity`），不和走路打架；被弹起来落地前不能动（和弹簧板一样）。马里奥心智不读素材包（H4）。

**还是要写代码的**：全新的行为（比如传送门、把人缩小、召唤东西）。上面这些组合起来已经能做出大多数陷阱和地形。

## 5. 自检
- AI 看图评审（拼图按游戏同规则画）：第一版过渡边太浅、直角、影子太淡（4/10）→ 加深毛边、加圆角、影子加深 → 第二版池塘圆角 + 水边、草泥边不规则、影子清楚。
- 还剩：路和路之间的拐角还是直角（路层级低于草，圆角只给高层级一方）；没有方向光影（只是脚下椭圆）。
