## 3. 本轮改动

### 新增

- `Assets/Scripts/WorldPark/BorderlandGame.cs`（+ `.meta`）：博弈内核，纯 C#、整数与固定伪随机，三种玩法：
  - `beauty` 数字猜心：每人写 0–100，最接近“平均 × ratio%”者不扣命。`escalate=1` 时有人出局后**每轮最多追加一条**规则（①同数字无效 ②正好命中时其他人扣两条命），**只剩两人时优先宣布决斗规则**（有人写 0 时写 100 的人获胜）。剩两人时除直觉型外的 NPC 会写 0（“更小的数一定赢”），所以决斗规则才有意义。
  - `mark` 看不见的标记：自己的花色只能听别人说；说谎者第一轮说真话做饵；每轮公开真相，可据公开记录识破说谎者。
  - `split` 分还是偷：轮流对不同参与者，先听承诺再选；双分各 +1，偷对分 +2 且对方失去一命，双偷 0；玩家背叛过“选分的人”会留下公开名声；最后一轮有人背叛。
  - 人格：`player`（恰好一位）、`naive`、`reasoner`、`deep`、`adaptive`、`liar`、`loyal`、`mirror`。上限：座位 2–8，轮数 ≤ 20，命数 ≤ 20。
- `Tools/LevelStudioWeb/borderland.js`：与 C# 逐字同语义的网页内核（由 `build.py` 先于 `worldpark.js` 内联）。
- `Assets/Resources/WorldPark/Borderland.worldpark.json`（+ `.meta`）：主世界“空白之城”，五个原创会场：♣3 三扇门（35 秒探索，字面陷阱）→ ♦5 数字猜心 / ♥7 看不见的标记 → ♥9 分还是偷 → K 主办者的房间（最终真相与“离开/留下”）。
- `Tools/WorldParkVerify/Story/`（`Program.cs`、`WorldParkStory.csproj`、`Borderland.expect.json`）：剧情带入模拟器。5 种人格玩家**只凭公开信息**真实移动、调查（含每秒 10 字的阅读耗时；运行器读线索时计时不停）、博弈、跨会场旅行并读写检查点；输出 `.work/worldpark-verify/story/模拟报告.md` 和 `旅程_*.md`；检验作者预期、公平（至少一种公开信息策略能活）、威胁（至少一种策略出局）、规则追加真的生效、限时压迫（存活者用时 ≥ 40%）、结局多样、检查点一致。
- `Tools/WorldParkVerify/web-game-smoke.cjs`：用桩 DOM 加载真实网页脚本，经彩排面板逐轮打完 ♦5 并提交，检查 ♥7/♥9 按钮、坏 JSON 防护等（12 断言）。

## 4. 模拟驱动的修正（这就是“用剧情检验”的价值）

| 第一次模拟发现的问题 | 修正 |
|---|---|
| 三人同时出局时一次塞进两条新规则，玩家来不及感受 | 每轮最多追加一条 |
| 第三条规则在 NPC 行为下永远不会触发（没有 NPC 写 0） | 剩两人时聪明 NPC 写 0；决斗规则在剩两人时立即宣布 |
| 玩家已出局那一轮还宣布“下一轮起”的新规则 | 游戏结束的那轮不再宣布 |
| 三扇门限时 60 秒，存活者只用掉 12%，没有压迫感 | 加入阅读耗时模型，限时改 35 秒（存活者最少用掉 53%） |
| 数字猜心里“跟随者”从不撞车，“同数字无效”形同虚设 | 加入第二位跟随者“鸣”，规则在挑战中生效 4 次 |
| 剧情记录里人格想法格式不统一 | 统一为“（某某心里想：…）” |
