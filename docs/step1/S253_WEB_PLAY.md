## 1. 为什么做这一轮

用户 15:01 的要求是“还是需要做游戏，不是文字阅读”。S252 已经把 Unity 里的世界做成了可玩的游戏代码（全屏博弈桌、字幕卡、演出层、♠5 鬼抓人），但本机 Unity 许可证没有激活，**没有任何人（包括我）在屏幕上真正玩过**。最大的缺口因此不是再加内容，而是“让用户今天就能玩到，并且让我能看到画面来检验体验”。

S253 的答案是**网页试玩**：在已有的网页设计台（`Tools/LevelStudioWeb/index.html`，单文件、离线可用）里加一个全屏游玩层，使用与 Unity **同语义**的规则内核，从霓虹亮灯入场一直玩到旅程总结。Unity 仍是正式运行端；网页试玩是“今天就能玩、改完马上试”的第二个运行端。

## 3. 玩家看到什么

入口有三个：网页顶部 **▶ 网页试玩**（玩当前世界草稿）；“世界乐园”页工具栏 **▶ 网页试玩这个世界**；或直接打开 `index.html#play`（玩内置主世界“空白之城”）。

一次完整旅程：标题页（有存档时显示“继续旅程”）→ 霓虹扑克牌通电亮起，报出会场名、难度、花色与 GAME START → 电影画幅字幕卡逐字出现 → 俯视现场（WASD / 方向键移动，E 调查或开门；视野外变暗；线索卡弹出并记入线索本；限时会场有计时器，最后 10 秒大字倒计时，5 秒内变急促）→ ♠5 里鬼沿巡逻路线走、视锥可见，被看见时报警、画面边缘闪红，站在高草里不动可以躲 → 出口或被抓时演出“通过 / 出局”激光 → 结果面板 → 揭示字幕卡逐张翻开“当时以为 → 其实”的反转卡（没发现的线索只告诉你错过了）→ 结局盖 GAME CLEAR / GAME OVER 章，下一个会场显示成可点的门（关着的门写明条件）→ 博弈会场是全屏博弈桌：座位环绕牌桌，对你说的话显示在说话人旁边，提交后逐张翻牌，标出得分、扣命、出局 → 最终 K 主办者的房间 → 旅程总结。

辅助：Tab 线索本 / 博弈记录；Esc 暂停（继续、重来本会场、回到标题、退出试玩）；顶栏声音开关（程序合成音效，不需要音频文件）；GAME OVER 后可以“重来本会场”。进度在剧情 / 揭示 / 结局这些安全阶段自动存在本浏览器（`localStorage`，按世界内容区分），探索与博弈进行中不存，与 Unity 检查点规则一致。

## 4. 真实浏览器自动试玩（新验证步骤）

`Tools/WorldParkVerify/web-play-smoke.cjs` 用本机的无界面 Edge（找不到时用 Chrome）打开真实构建出来的 `index.html#play`，通过调试协议发送**真实按键与点击**走完主世界：♣3 三扇门 → ♠5 鬼抓人（第一次故意站到鬼面前：被发现 → 被抓 → 出局激光 → GAME OVER → 重来本会场；第二次正常调查后通过）→ ♥9 分还是偷（博弈桌逐轮打完）→ K 主办者的房间 → 旅程总结。过程中收集页面脚本错误、检查入场霓虹不透明度、结果面板不能出现内核提示文字、字幕卡循环不能失控，并截图 21 张到 `.work/worldpark-verify/web-play/`。

最近一次结果：走过 4 个会场，字幕卡 15 张，反转卡逐张亮出 6 张，现场 4 次（线索卡 8 次），博弈 1 场，演出 entrance×5 / pass×4 / laser×1，入场霓虹不透明度全部 1.00，被抓后重来 1 次，错误 0，用时约 45 秒。

环境说明：命令沙箱里浏览器的 GPU / 渲染子进程会因权限被拒（0xC0000022）而崩溃，所以脚本使用 `--no-sandbox --in-process-gpu --remote-allow-origins=*` 并只连接 127.0.0.1 随机端口；在 Manus 的受限命令环境里运行需要允许本机回环网络。没有浏览器或连不上调试端口时输出 SKIP（环境问题），游戏本身的问题照常 FAIL。已接入 `run_all.ps1`（步骤名“S253真实浏览器试玩”，位于网页重建之后）。

## 5. 按截图修掉的问题

真实画面暴露了纯逻辑测试看不到的问题，全部已修并由冒烟脚本覆盖：

1. 入场霓虹等关键内容原先靠“从透明开始”的 CSS 动画显现，无界面浏览器和低性能机器上可能一直不可见 → 改为由游戏时钟逐帧驱动，冒烟检查不透明度。
2. 顶栏按钮在窄屏换行；会场名已含牌面时（“♣3 三扇门”）又重复一次牌面。
3. 博弈桌：座位整块居中在模型坐标上，顶部座位压住轮次文字，玩家自己的座位被操作按钮盖住 → 桌面底部让出 150px 给操作区，座位改为以头像中心对齐模型坐标，自己的牌放在头像右侧，轮次移到左上，状态框移到左下。座位坐标本身仍来自与 Unity 共用的模型，没有改。
4. 结局章旋转后压住下一行；现场结果面板显示了内核提示“出口已锁定；请确认后提交现场结果” → 改为给玩家看的话（“你打开了「…」”“你被「走廊的鬼」抓住了”“时间到了”）。
5. 旅程总结行重复牌面（“♣3 ♣3 三扇门”）→ 这是共用模型的行为，**C# `WorldParkSceneModel.cs` 与 `play-model.js` 同时修改**（会场名已以牌面开头就不再加牌面），跨端对比仍为 0 差异。
6. 没有可走的门时结局页出现两个“结束旅程”按钮。
7. 旧“网页博弈彩排冒烟”的桩 DOM 没有 `location`，新加的 `#play` 自动打开会报错 → 加环境判断。

4. 继续开拓新会场时，每个会场都先在网页试玩里走通，再跑剧情带入模拟。
