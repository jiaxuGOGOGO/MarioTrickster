## 拆解时发现、但本轮没改的问题（详见指南第 12 节）

1. 博弈参数只能手写 JSON。2. 世界工坊里不能画探索地形（只能打字或从小镇页复制），画布挤在右栏只看得到半张图。3. 阶段靠下拉框选 ID 连接，没有流程图。4. 到处是 ID 和英文字段名。5. 鬼的巡逻路线要手写坐标。6. 公开规则是纯文字，改了限时不会跟着变。7. 门是全世界共用一张表却放在会场面板里，条件要手打。8. 旧系统残留：玩家角色（捣蛋者）、守宝房、两处“阶段彩排”（提示还写着结果由 Unity 决定）、探索区“这是作者表单，不是另一个网页游戏”、“交给 AI”页还写着发给 Genspark / 升级包。9. 反转卡要作者自己推算谁会看到。10. **现场探索阶段的“玩家可见的文字”在网页试玩里不显示**（`play.js` 的 `showExplore` 没有用到 `node.text`；Unity 有入场说明）——这是两端演出不一致，规则内核不受影响。11. 签证只是“难度 = 天数”的装饰，没有原作的跨会场签证倒计时。
