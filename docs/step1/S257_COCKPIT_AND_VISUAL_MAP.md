# S257 图标驾驶舱与可视化地图创作

日期：2026-10-21。直接升级当前目录，不另做安装包，不提交或推送 Git。

## 作者只需要记住这一条路

**驾驶舱选会场 → 画地形 / 改大小 → 摆线索、门、鬼 → 只玩这个会场。**

双击 `Tools/LevelStudioWeb/index.html` 默认进入驾驶舱。网页仍然是原来的可离线打开单文件；`#play` 的直接试玩入口保留。

驾驶舱按当前世界数据画出会场、阶段、实际成功/失败去向、后续会场的门。点图标直接导航到相应编辑位置，不再从几十个字段里猜。没有探索地图或博弈阶段的会场，对应按钮灰掉并说明原因，不替作者凭空添加阶段。

## 为什么这样拆：先考虑作者要完成的事

作者要决定的是「场地长什么样、玩家在哪里做选择、选择导致什么、好不好玩」，不是维护 JSON 或辨认编号。因此导航改为任务入口；空间内容改成在图上画；流程用真实分支图标展示；保存和检查放在后台，用少量中文提醒。

每一步同时回答三个问题：**我正在改哪里？会影响什么？不满意怎样回去？** 驾驶舱与快捷导航显示当前会场和阶段。地图弹层明确标出编辑对象，未应用的改动只是临时预览，取消和 Esc 不改世界。应用之后仍通过原有 `wpPersist` 保存和记录，可用安全条撤销、重做、对照原版。不是第二个创作系统，也不是第二份世界数据。

## 地图现在不必手写文本

点「画地形 / 改大小」进入大画布子编辑器，默认看图块和标记。选择图块笔刷后点画或拖画，也可用矩形工具；弹层内支持“撤销画图 / 重做”（最近 50 步），只改变临时草稿。宽、高可以直接调，常用扩宽、扩高有按钮。放出生点会移动唯一的 T，不产生两个出生点。地图文本收进「显示高级格子」，仍可用来导入或精确排查。

扩图保留原内容，并打开扩张方向的旧边界、围好新的外圈。默认保持左下坐标，已有点位不平移；居中扩缩则同步平移点位和鬼的巡逻坐标。缩图若会裁掉出生点、点位或巡逻路线，会拒绝并说明，不能默默删掉。画墙若堵住已有点位、出口或巡逻格，也拒绝原图不变。所有通过的内容仍使用原世界地图字符和坐标规则；没有改变 C# 或网页运行内核。

地图子工具只负责地形和范围。线索、出口、鬼仍在原点位编辑器里放置和拖动；从驾驶舱进入它时，点位区域放大。鬼路线仍可用原坐标输入，本轮没有实现图上逐点画巡逻路线。

## 子创作如何接回世界

**会场地图：** 驾驶舱打开的是选中会场的探索阶段，不会跳到默认小镇。临时编辑后点「应用回当前阶段」，写回该阶段的 `mapText` 和必要的平移坐标，不修改其他会场、规则和线索台词。若打开后原阶段被其他操作改过，应用被拦，避免覆盖新改动。

**横版房间：** 世界工坊的横版挑战阶段可以从现有关卡库选房间，并直接打开那个房间子创作。顶部显示返回按钮及引用影响。改完「应用房间引用并返回」回到原会场原阶段；世界包只记房间名称，房间网格仍在原关卡库，需另存关卡包或沿用旧 Unity 同步。修改同名房间会影响所有引用该名字的阶段，界面标出引用数量。没有横版阶段时，驾驶舱也可以打开独立房间工具，但不会擅自替世界接入房间。

**旧小镇工具：** 作为独立地图素材工具保留。它不会自动改变任何会场；只有高级的「整张替换」按钮在说明并确认后才会复制进当前阶段。本轮不把小镇日程、门和居民自动混入世界规则，也不把旧小镇恢复成另一个主模式。

**正式游戏：** 驾驶舱给出「保存世界 → Unity 亲自试玩 → 构建 Windows」三个图标步骤，明确网页不能直接构建 exe。Unity 和网页仍读取同语义世界包；房间依赖仍需另外带上。完整依赖一键分享尚未实现。
