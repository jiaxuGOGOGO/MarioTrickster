# MarioTrickster 关卡设计台（网页）

**双击 `index.html` 用浏览器打开**（Chrome / Edge），不用安装、不用联网（没网时字体换成系统字体，功能不变）。
你的画布、批注、提案会自动存在这个浏览器里；换电脑用"保存项目 .json / 导入 .json"。

## 三个页面
| 页面 | 做什么 |
|---|---|
| **画关卡** | 用项目里全部元素画图（画笔/矩形/填充/吸管，右键擦除，Ctrl+Z 撤销）。右边实时显示：能不能玩、问题定位、死局格（红斜线）、马里奥的路线（红虚线）和**几秒走到哪个机关**的时间线。Alt+点格子写批注（"这里想要什么效果"）。 |
| **新机制提案** | 想一个新机关/技能/马里奥行为：它做什么、预警、代价、反制、能连哪些机关。提案马上出现在元素库里（金色虚线框），可以直接画进关卡试摆。会自动提醒哪几条项目硬规则（H1/H3/H4/H6/H9/A2）还没写清。也可以勾选"想删掉/改掉的旧东西"。 |
| **交给 AI** | 生成一份"设计单"（关卡图 + 时间线 + 预检问题 + 批注 + 提案 + 删改），复制发给 Genspark 的 AI："按这份设计单更新 MarioTrickster"。 |

## 和 Unity 的关系
- 元素表、样板都是从项目源码生成的（`build.py`），和 Unity 工坊一致；坐标同样是 x 从左 0、y 从下 0。
- 网页检查 = 快速预检（摆放规则、死局、路线时间线，规则移植自项目 C#）。**最终以 Unity 工坊 + AI 的完整体检为准**（炸弹困人模拟、三种性格自动检查、陷阱试探只在那边跑）。
- Unity 工坊"导入"可以直接读网页导出的 `.studio.json`（还没实现的新机制提案会先当空气）。

## 维护（给 AI）
元素/样板/规则有变化 → `python3 tools/LevelStudioWeb/build.py` 重新生成 `index.html`，并随升级包一起交付。改网页逻辑改 `logic.js`（纯逻辑，可用 node 测）/ `app.js`（界面）/ `shell.html`（样式与结构）。
