# MarioTrickster 关卡设计台（网页）

**双击 `index.html` 用浏览器打开**（Chrome / Edge），不用安装、不用联网（没网时字体换成系统字体，功能不变）。
你的画布、批注、提案会自动存在这个浏览器里；换电脑用"保存项目 .json / 导入 .json"。

## 三个页面
| 页面 | 做什么 |
|---|---|
| **画关卡** | 用项目里全部元素画图（画笔/矩形/填充/吸管/移动，右键擦除，Ctrl+Z 撤销）。右边实时显示：能不能玩、问题定位、死局格（红斜线）、马里奥的路线（红虚线）和**几秒走到哪个机关**的时间线。Alt+点格子写批注（"这里想要什么效果"）。 |
| **新机制提案** | 想一个新机关/技能/马里奥行为：它做什么、预警、代价、反制、能连哪些机关。提案马上出现在元素库里（金色虚线框），可以直接画进关卡试摆。会自动提醒哪几条项目硬规则（H1/H3/H4/H6/H9/A2）还没写清。也可以勾选"想删掉/改掉的旧东西"。 |
| **交给 AI** | 生成一份"设计单"（关卡图 + 时间线 + 预检问题 + 批注 + 提案 + 删改），复制发给 Genspark 的 AI："按这份设计单更新 MarioTrickster"。 |

## S217 新增（大地图）
- **↔ 扩展地图…**（大地图页工具条）：四周各 +8/+16、只往一个方向 +16、宽高 ×2、裁掉一圈。老镇原样保留，新地铺草、外圈自动种树；最大 192×128。旁边显示当前尺寸，⤢ = 缩放到整张图。和 Unity 小镇工坊"↔ 扩展"完全同一套规则。

## S208 新增（不知道从何下手？从这里开始）
- **＋ 新关卡（向导）**：三步——写一句话点子（可空）→ 选主角机关（8 种）→ 选时长（20 / 30 / 40 秒）→ 生成一张**已经能玩**的草稿，按"起承转合"4 段摆好，每段有批注告诉你怎么玩。第一次打开网页会自动弹出。同样的选择永远生成同样的草稿。
- **模式印章（S）**：左边 8 个现成的小积木（伏击点 / 滑铲送火 / 高低两路 / 陷坑回廊 / 弹射落点 / 关门打狗 / 回马枪 / 炮台走廊）。选一个，鼠标放到马里奥站的那格，预览满意再点。右键退出，Ctrl+Z 撤销。
- **起承转合**（显示组）：金色虚线 4 段 = 起（教）→ 承（加深）→ 转（意外）→ 合（收尾）。
- **节奏条**（右栏）：红 = 马里奥正经过机关（去程+回程），绿 = 喘气。连续红 ≥8 秒或连续绿 ≥10 秒会提醒。
- **转移点提示**（显示组）：橙圈 = 马里奥会路过的机关 5 格内没有草丛/箱子——你伪装着站着不会被怀疑，但走过去的路上会被看见。

## S207 新增
- **移动工具（V）**：点住已放的东西拖走（整座塌桥这类连在一起的会一起走）；空白处拖 = 框选；方向键挪 1 格；Del 删除；Ctrl+C / Ctrl+V 复制粘贴；Esc 取消。外圈墙、马里奥/捣蛋者/宝物/出口受保护。
- **吸管**：点一下画笔就变成它，并自动回到原来的工具；随时 Ctrl+点击也能吸。
- **"显示（只改画面）"**：这一组勾选框只改变画面上显示什么，不改关卡、不影响检查和导出。鼠标停上去有解释。
- **游戏一屏**：蓝框 = 游戏里一屏能看到多大。大房间（宽 >64 或高 >16）游戏里镜头会跟着人走（死亡细胞式），马里奥在屏外有红箭头，右上角有小地图。

## S205 新增
- **跳跃辅助**：鼠标停在马里奥能站的格子上 → 绿色 = 从这里跳一下能到（AI 会走），黄色 = 物理上够得着但 AI 不稳（别把必经路放这，H8）。
- **上不去的格**：紫色点 = 能站但马里奥永远上不去的地方（台子太高、坑太深、被墙隔开）。
- **导入多种格式**：本设计台 .json、Unity 工坊 .txt、**Tiled** 导出的 .json / .csv、**LDtk** 的 .ldtk / 超简导出 .csv、**像素图** .png（1 像素 = 1 格，按颜色认元素）。数字格式会弹窗让你把每种数字对应到元素。
- **导出像素图 / 调色板**：拿去 Piskel、Aseprite、Windows 画图里改，改完导入回来。

## 和 Unity 的关系
- 元素表、样板都是从项目源码生成的（`build.py`），和 Unity 工坊一致；坐标同样是 x 从左 0、y 从下 0。
- 网页检查 = 快速预检（摆放规则、死局、路线时间线，规则移植自项目 C#）。**最终以 Unity 工坊 + AI 的完整体检为准**（炸弹困人模拟、三种性格自动检查、陷阱试探只在那边跑）。
- Unity 工坊"导入"可以直接读网页导出的 `.studio.json`（还没实现的新机制提案会先当空气）。

## 维护（给 AI）
元素/样板/规则有变化 → `python3 tools/LevelStudioWeb/build.py` 重新生成 `index.html`，并随升级包一起交付。改网页逻辑改 `logic.js`（纯逻辑，可用 node 测）/ `app.js`（界面）/ `shell.html`（样式与结构）。
