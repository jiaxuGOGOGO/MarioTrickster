# S206：关卡库 · 搭建范围 · 新机制确认 · 导入流程（一次讲清楚）

## 1. 搭建范围（网页和 Unity 同一套规则）
| 规则 | 数值 |
|---|---|
| 房间大小 | 宽 **12–128** 格、高 **6–48** 格 |
| 外圈 | 最左、最右一列必须是墙 `W`；最上一行、最下一行必须全实心（马里奥不能掉出地图） |
| 必须有 | `M` 马里奥 · `T` 你 · `G` 出口 · `o` 宝物，各 1 个 |
| 马里奥能力 | 往上跳 ≤2 格（左右偏 ≤2 格）；平跳 ≤4 格宽的坑；再远 = 黄色（临界）或上不去 |
| 镜头 | 高 ≤16 格：整屏看全图；更高：镜头跟着人走（能玩，只是看不全） |
| 摆放 | 脚下要实心的物件、弹簧头顶 4 格、炮口前 3 格、毒池 ≤3 格、绳套/铁笼头顶 2 格、通风管成对 |

网页左边有"搭建范围"提示框；超出范围直接报错。

## 2. 你自己搭的关卡：自动检查什么
- **死局**（红斜线）：塌桥/裂缝/门/裂墙打开后回不去的格。
- **上不去的格**（紫点）：能站但马里奥永远到不了（台太高、坑太深、被墙隔开）。四个样板没有，是因为它们本来就修好了；你自己搭的图出现了会马上标出来。
- **跳跃辅助**：鼠标停在格子上，绿 = 跳一下能到，黄 = 够得着但 AI 不稳。
- **炸弹困人、三种性格自动通关**：只在 Unity / AI 完整检查里跑（网页不跑）。

## 3. 搭很多关：关卡库
**网页**：左边"我的关卡"列表（每关有名字、绿点=预检通过/红点=有问题、⏳=用到还没实现的提案）。＋新关卡 / 复制 / 删除；载入样板、导入文件都会**新增一关**，不会覆盖你的。全部自动存在浏览器里。
**导出关卡包**：右上角"导出关卡包 .json" = **所有关卡 + 所有提案，一个文件**（文件名带关数和日期）。这是你的备份，也是给 Unity / AI 的数据。
**Unity**：工坊工具条 **"关卡库 ▾"**
- 导入网页关卡包 → 每关存成 `Assets/Levels/Library/关卡名.txt`（名字就是网页里的名字，同名覆盖 = 更新）；
- 打开/关卡名 → 载入画布，点"▶ 作为第 1 步房间试玩"；
- 存入关卡库 → 把工坊里改过的图按名字存回去。
关卡库在项目文件夹里，**跟着 git 上传**，换电脑、换账号都在。

## 4. 新机制/技能怎么确认新增
网页"新机制提案"每个提案有状态：
| 状态 | 意思 | AI 会做什么 |
|---|---|---|
| 💡 想法 | 还在想 | 只讨论、给建议（和现有机制重复吗？怎么更好玩？），**不实现** |
| ✅ 确认要做 | 想清楚了 | 按项目规则实现（补齐预警/代价/反制的默认值并告诉你），加测试、进元素库 |
| ✔ 已实现 | 项目里已经有了 | 不动 |
提案可以先画进关卡试摆（金色虚线框）。表单下面会提示还没写清的硬规则（H3 预警、A2 代价和反制、H9 控人时长、H1 改地形）。

## 5. 新增后怎么导入关卡（关键：先画后实现，格子不丢）
1. 网页里用提案字符（比如 `A` 磁铁）画进关卡 → 导出关卡包。
2. 这时导入 Unity：`A` 格**先当空气**，文件里记一行 `# Pending: A=磁铁陷阱 (5,3)`，关卡库列表显示 ⏳A。能先试玩其它部分。
3. 把**设计单 + 关卡包**交给 AI → AI 实现磁铁（字符 A 正式登记）→ 交付升级包 + 新网页。
4. 装好升级包后，在 Unity 再导入**同一个关卡包** → 同名覆盖，`A` 格自动还原成真正的磁铁。网页换成新版后，提案自动变成正式元素。

## 6. 换账号
把三样发给新账号的 AI：**接续包 .skill + 设计单 + 关卡包 .json**，说"按设计单更新 MarioTrickster"。它会按接续包的规则做完并交付；你装升级包，再在 Unity 导入关卡包测试。
